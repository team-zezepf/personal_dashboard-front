伝送や記憶で起きたビット誤りに対し、誤りの有無だけを見つけるのが検出、誤った位置を特定して直すのが訂正。パリティビットは検出のみ、ハミング符号は1ビットの訂正までできる。

インタフェースが異なるクラスを、既存のコードの呼び出し方に合わせて変換して使えるようにするデザインパターン。

ARPあーぷ / Address Resolution Protocolテクノロジ系

IPアドレスから、同じLAN内の機器のMACアドレスを求めるプロトコル。ブロードキャストで問い合わせ、結果をARPテーブルに保存する。

関連: ネットワーク › 3. TCPのコネクション確立とアドレス解決・名前解決

AS(自律システム)えーえす / Autonomous Systemテクノロジ系

1つの組織が一貫した方針で管理するネットワークのまとまり。AS内はIGP、AS間はEGPで経路制御する。

関連: ネットワーク › 1. ネットワーク層とルーティングプロトコル

B+木びーぷらすぎテクノロジ系

B木の葉(リーフノード)どうしを連結し、範囲検索を高速にした木構造。多くのRDBMSのインデックスに使われる。

関連: データベース › 4. インデックス(B木)と分散データベースの設計判断

BAC(完成時総予算)びーえーしー / Budget At Completionマネジメント系

プロジェクト全体の当初の予算総額。

関連: プロジェクトマネジメント › 4. アーンドバリューマネジメント(EVM)による定量的な進捗管理

BASE特性べーすとくせいテクノロジ系

Basically Available・Soft state・Eventually consistent。厳格な整合性より可用性を重視し、最終的に整合性が取れればよいとする、多くのNoSQLの設計思想。

関連: データベース › 4. インデックス(B木)と分散データベースの設計判断

BDATストラテジ系

EAで組織全体をとらえる4つの観点。ビジネス・データ・アプリケーション・テクノロジの各アーキテクチャ。

関連: システム戦略 › 1. 情報システム戦略における全体最適化の手法(EA・BPR・ERP)

BGPBorder Gateway Protocolテクノロジ系

AS(自律システム)どうしを接続するパスベクトル型のルーティングプロトコル。経路制御のポリシーを重視する。

関連: ネットワーク › 1. ネットワーク層とルーティングプロトコル

C0網羅・C1網羅しーぜろもうらテクノロジ系

命令網羅(C0)と分岐網羅(C1)の別名。C1はすべての分岐の真・偽を通すため、C0より厳しい基準。

関連: システム開発技術 › 3. テスト技法(ホワイトボックス/ブラックボックス)

CAB(変更諮問委員会)きゃぶ / Change Advisory Boardマネジメント系

変更管理で、変更要求(RFC)の影響を評価し、実施の可否を審査する委員会。緊急時は少人数のECABで迅速に承認する。

関連: サービスマネジメント › 3. 変更管理(CAB)とキャパシティ管理

CAP定理きゃっぷていりテクノロジ系

分散システムでは、一貫性(C)・可用性(A)・分断耐性(P)の3つを同時に満たすことはできないという定理。

関連: データベース › 4. インデックス(B木)と分散データベースの設計判断

COBITこびっとマネジメント系

経営目標を達成する観点からITの統制目標を定義し、成熟度を評価するITガバナンスのフレームワーク。

関連: サービスマネジメント › 1. ITILの全体像とSLA・OLA・UCの関係

Cookieくっきーテクノロジ系

Webサーバがブラウザに保存させる小さなデータ。ログイン状態の保持などに使われ、XSSやCSRFで悪用される。

関連: セキュリティ › 3. Webアプリケーションへの攻撃(SQLインジェクション・XSS・CSRF)とWAF

COSOフレームワークこそふれーむわーくストラテジ系

内部統制の代表的な枠組み。統制環境・リスクの評価と対応・統制活動・情報と伝達・モニタリング・ITへの対応などの基本的要素からなる。

関連: 企業と法務 › 5. コーポレートガバナンス・内部統制・コンプライアンス

CRYPTRECくりぷとれっくテクノロジ系

電子政府推奨暗号リストを作るなど、暗号技術の安全性を評価・監視する日本の政府のプロジェクト。

関連: セキュリティ › 4. ゼロデイ攻撃と脆弱性の深刻度評価(CVE・CVSS)

CV(コスト差異)しーぶい / Cost Varianceマネジメント系

EV − AC。正なら予算内、負ならコスト超過。

関連: プロジェクトマネジメント › 4. アーンドバリューマネジメント(EVM)による定量的な進捗管理

CVECommon Vulnerabilities and Exposuresテクノロジ系

個々の脆弱性に一意の識別番号を付け、世界共通で識別できるようにする仕組み。

関連: セキュリティ › 4. ゼロデイ攻撃と脆弱性の深刻度評価(CVE・CVSS)

CVSSCommon Vulnerability Scoring Systemテクノロジ系

攻撃元区分・攻撃条件の複雑さ・必要な権限・影響範囲などから、脆弱性の深刻度を0.0〜10.0のスコアで評価する共通基準。

関連: セキュリティ › 4. ゼロデイ攻撃と脆弱性の深刻度評価(CVE・CVSS)

DaaSだーす / Desktop as a Serviceストラテジ系

仮想デスクトップ環境そのものをインターネット経由で提供するクラウドサービス。

関連: システム戦略 › 3. クラウドサービスの提供形態と管理範囲(SaaS・PaaS・IaaS・DaaS)

DNSのレコードでぃーえぬえすのれこーどテクノロジ系

DNSが管理する情報の種類。Aレコード(IPv4アドレス)、AAAAレコード(IPv6アドレス)、MXレコード(メールサーバ)、NSレコード(権威DNSサーバ)、CNAMEレコード(別名)、PTRレコード(逆引き)など。

関連: ネットワーク › 3. TCPのコネクション確立とアドレス解決・名前解決

関連: プロジェクトマネジメント › 4. アーンドバリューマネジメント(EVM)による定量的な進捗管理

実行時間が最も短いプロセスを優先してCPUを割り当てるスケジューリング方式。平均待ち時間は短くなるが、長いプロセスが待たされ続けることがある。
