基礎理論のまとめ

2進数・論理演算・数値表現など、基礎理論で問われる要点を図解しています。読み終えたら下部から問題を解いて定着させましょう。

1基数変換(2進数・8進数・16進数)

コンピュータは内部で2進数(0と1)を使ってデータを扱う。桁数が多く読みにくいため、人が扱う際は8進数や16進数で短く表記することが多い。

10進数2進数8進数16進数
0000000
7011177
10101012A
15111117F
例題: 2進数 1101 → 10進数 1101(2) = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = 13
例題: 16進数 2F → 10進数 2F(16) = 2×16¹ + 15×16⁰ = 32 + 15 = 47(A〜Fはそれぞれ10〜15を表す)

逆に10進数をn進数に変換するには「基数で割り続け、余りを下から順に並べる」除算法を使う。商が0になるまで基数で割り、出てきた余りを最後から先頭へ向かって並べると変換後の数値になる。

例題: 10進数 26 → 2進数 26 ÷ 2 = 13 余り 0
13 ÷ 2 = 6 余り 1
6 ÷ 2 = 3 余り 0
3 ÷ 2 = 1 余り 1
1 ÷ 2 = 0 余り 1
余りを下から上に読むと 26(10) = 11010(2)
例題: 10進数 200 → 16進数 200 ÷ 16 = 12 余り 8
12 ÷ 16 = 0 余り 12(C)
余りを下から上に読むと 200(10) = C8(16)(余り12はCと表記)
つまずきやすいポイント 8進数・16進数はどちらも「各桁の重み(8のn乗、16のn乗)×桁の値」を足し合わせるだけで10進数に変換できる。基数(2, 8, 16)が違うだけで考え方は同じ。逆方向(10進数→n進数)は割り算の「余り」を使う点が、10進数への変換(掛け算で重みを足す)と逆になることを意識するとよい。

2論理演算と論理回路

論理演算は0/1(偽/真)を扱う演算で、論理回路図は演算の組み合わせを図で表したもの。まずは基本の6種類の入出力を覚える。

ABANDORXORNANDNOR
0000011
0101110
1001110
1111000

論理回路図では、ゲートの形そのものが種類を表す。AND/NANDは左辺が直線+右側が半円、OR/NOR/XORは背面がへこみ先端がとがった形、NOTは三角形。NAND・NOR・NOTの出力側についている小さな丸は「反転(否定)」を表す。

AND: 両方1のとき1
OR: どちらかが1で1
NOT: 入力を反転(丸は反転を表す)
XOR: 異なるとき1(ORに入力側の二重線)
NAND: ANDの反転(出力に丸)
NOR: ORの反転(出力に丸)
ド・モルガンの法則 ¬(A ∧ B) = ¬A ∨ ¬B　(「AかつBでない」は「Aでない、またはBでない」)
¬(A ∨ B) = ¬A ∧ ¬B　(「AまたはBでない」は「Aでない、かつBでない」)

3数値の表現方法

コンピュータが数値を2進数で表現する方式には、小数点の位置を固定する方式と、指数を使って可変にする方式がある。

例題: 2の補数(負の数の表現)の求め方 各ビットを反転(0→1, 1→0)し、最後に1を加える。
例: 5 = 00000101 → 反転 11111010 → +1 → 11111011(これが -5 を表す)
つまずきやすいポイント 「1の補数」は反転するだけ、「2の補数」はさらに+1する。混同しやすいので注意。固定小数点数は精度・範囲が固定、浮動小数点数は指数部により広い範囲を表現できる。

4誤り検出(パリティビット)

データ伝送中の誤りを検出するため、データに1ビット付加して1の個数を偶数(偶数パリティ)または奇数(奇数パリティ)にそろえる。受信側で1の個数を数え、想定と異なれば誤りと判断できる。

例題: 受信側がどうやって誤りに気づくか(偶数パリティの場合) 正常な場合: 「1011」+パリティ「1」を受信 → 1の個数は4個(偶数) → 想定通りなので正常と判断。
伝送中に1ビットが化けた場合: 3ビット目が反転し「1001」+パリティ「1」を受信 → 1の個数は3個(奇数) → 「偶数のはず」という想定と異なるため誤りと判断できる。
つまずきやすいポイント パリティビットで分かるのは「誤りが起きたこと」だけで、「どのビットが化けたか」は特定できない。また2ビット同時に反転すると1の個数の偶奇が元に戻ってしまい、誤りを検出できない(パリティチェックの限界)。
