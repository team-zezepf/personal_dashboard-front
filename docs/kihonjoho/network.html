ネットワークのまとめ

LAN/WANの基礎からTCP/IPの階層構造、IPアドレスとサブネット、代表的なプロトコル(電子メールを含む)、伝送時間の計算、IoTの無線通信、ネットワーク機器、セキュリティまで、ネットワークで問われる要点を図解しています。読み終えたら下部から問題を解いて定着させましょう。

1ネットワークの基礎(LAN/WANと接続形態)

ネットワークは規模によって分類され、会社や家庭など比較的狭い範囲を結ぶ「LAN(Local Area Network)」と、地理的に離れた拠点間を結ぶ「WAN(Wide Area Network)」に大別される。LAN同士やLANとWANを接続することで、より広い範囲との通信が可能になる。

接続形態(トポロジ)特徴
スター型集線装置(ハブ等)を中心に、各端末が個別の線で接続される形態。現在最も一般的。
バス型1本の幹線(バスケーブル)に全端末を接続する形態。
リング型端末を環状に接続し、データを順に受け渡す形態。
メッシュ型端末同士を網目状に接続し、複数の経路を確保する形態。

無線LAN(Wi-Fi)は、IEEE802.11シリーズとして標準化された無線通信を用いるLAN技術の総称であり、無線LANアクセスポイントを介して端末をネットワークに接続する。有線LANと組み合わせて利用されることが多い。

ネットワーク上で送受信されるデータは、そのまま送るのではなく一定の大きさに分割される。この分割された単位を「パケット」と呼び、宛先情報などを記録した「ヘッダ」が付加される。

つまずきやすいポイント データリンク層で扱う「フレーム」、ネットワーク層で扱う「パケット」、トランスポート層で扱う「セグメント」は、いずれも通信データの分割単位を指す言葉だが、扱う階層によって呼び方が異なるだけである。
練習問題 0 / 2問 正解

問1　集線装置(ハブなど)を中心に、各端末を個別のケーブルで接続するネットワークの接続形態はどれか。

スター型は中央の集線装置に各端末をつなぐ形態で、1本のケーブルの障害が他の端末に影響しにくく、現在最も一般的。バス型は1本の幹線に全端末をつなぎ、リング型は環状につないで順に受け渡し、メッシュ型は網目状につないで複数の経路を確保する。

問2　ネットワーク層(TCP/IPのインターネット層)で扱う、通信データの分割単位を表す用語はどれか。

ネットワーク層で扱う単位はパケット。データリンク層ではフレーム、トランスポート層(TCP)ではセグメントと呼ぶ。メッセージは、アプリケーションがやり取りするデータ全体を指すことが多い。

問1　OSI参照モデルで、経路選択(ルーティング)やIPアドレスによるアドレッシングを担う層はどれか。

ネットワーク層(第3層)は、異なるネットワーク間の経路選択とアドレッシングを担い、IPが代表的なプロトコル。トランスポート層は端末間の信頼性の確保(TCP・UDP)、データリンク層はMACアドレスによる隣接機器間の転送、セッション層は通信の開始・終了の管理を行う。

問2　UDPの説明として、適切なものはどれか。

UDPは接続の確立を行わず、信頼性より速度を優先するため、動画・音声の配信やDNSの問い合わせに使われる。イはTCPの説明。ウはIP(ネットワーク層)、エはデータリンク層の説明。

3IPアドレスとサブネットマスク

IPv4のIPアドレスは32ビットで構成され、8ビットずつ4つに区切って10進数で表記する(例: 192.168.1.1)。IPアドレスは「ネットワーク部」と「ホスト部」からなり、ネットワーク部は所属するネットワークを、ホスト部はそのネットワーク内の個々の機器を識別する。

サブネットマスクは、IPアドレスのうちどこまでがネットワーク部でどこからがホスト部かという境界を示すために用いられる値である。ネットワーク部を1、ホスト部を0のビットで表し、IPアドレスと同じ32ビットで表記する。「/26」のように、ネットワーク部のビット数をそのまま後ろに付ける表記をCIDR表記と呼ぶ。

例題: 192.168.1.0/26 で割り当て可能なホスト数 「/26」はホスト部が 32-26=6ビット。アドレス総数は 2⁶=64個。そこから「ネットワークアドレス」と「ブロードキャストアドレス」の2個を除いた 64-2=62個がホストに割り当て可能な最大数となる。
つまずきやすいポイント ホスト部が全て0のアドレスは「ネットワークアドレス」(ネットワークそのものを指す識別子)、全て1のアドレスは「ブロードキャストアドレス」(ネットワーク内全体への一斉送信用)であり、どちらも個々の機器には割り当てられない。ホスト数を求める際は必ずこの2個を引くことを忘れない。

IPv4はアドレス空間が32ビット(約43億個)であり、インターネットの普及に伴いアドレスの枯渇が問題となった。この対策として、128ビットという非常に広大なアドレス空間を持つIPv6が策定されている。

練習問題 0 / 2問 正解

問1　IPv4のネットワーク 172.16.5.0/27 で、ホストに割り当てられるIPアドレスは最大何個か。

ホスト部は 32 − 27 = 5 ビットで、アドレスは 2⁵ = 32 個。ホスト部が全て0のネットワークアドレスと、全て1のブロードキャストアドレスを除いた 30 個がホストに割り当てられる。イは2個を除き忘れた値、ウは /26、エは /28 の場合の値。

問2　IPv4のネットワーク 192.168.10.64/26 のブロードキャストアドレスはどれか。

ホスト部は6ビットなので、このネットワークのアドレスは 64 から 64 + 63 = 127 まで。ホスト部が全て1の 192.168.10.127 がブロードキャストアドレスになる。イはホスト部が全て0のネットワークアドレス、アは1つ前のネットワーク(.0/26)のブロードキャストアドレス、エは /24 とみなした場合のブロードキャストアドレス。

4ネットワーク機器とルーティング

機器主に扱う層役割
リピータハブ物理層受信した信号を増幅し、宛先を区別せず全ポートへそのまま中継する
スイッチングハブデータリンク層接続機器のMACアドレスを学習し、宛先の機器にのみデータを転送する
ルータネットワーク層宛先IPアドレスをもとに、異なるネットワーク間でパケットを中継する
リピータハブ: 信号をそのまま全ポートへ中継
スイッチングハブ: MACアドレスで宛先を判別
ルータ: IPアドレスで経路を選択

異なるネットワークセグメント間でパケットを中継する際、宛先IPアドレスをもとに最適な経路を選択する処理を「ルーティング」と呼ぶ。ルータはこのルーティングを行うことで、LANとインターネットのような異なるネットワーク同士の通信を実現する。

端末が自ネットワークの外(異なるネットワーク)へ通信する際、最初にパケットを送信する中継機器のアドレスを「デフォルトゲートウェイ」と呼ぶ。通常はルータのIPアドレスが設定される。

つまずきやすいポイント 「ハブ(リピータハブ)」は同一セグメント内で信号をそのまま中継するだけで、異なるネットワークを繋ぐことはできない。異なるネットワーク間の接続・中継には必ず「ルータ」が必要になる、という区別が頻出のポイント。
練習問題 0 / 2問 正解

問1　接続された機器のMACアドレスを学習し、宛先の機器が接続されているポートにだけデータを転送するネットワーク機器はどれか。

スイッチングハブはデータリンク層の機器で、MACアドレスで宛先を判別する。リピータハブ(物理層)は宛先を区別せず全ポートへ中継する。ルータ(ネットワーク層)はIPアドレスをもとに異なるネットワーク間でパケットを中継する。プロキシサーバはクライアントの代理でサーバにアクセスするサーバ。

問2　端末が自分のネットワークの外と通信するとき、最初にパケットを送る中継機器(通常はルータ)のアドレスを何というか。

デフォルトゲートウェイは、他のネットワークへの出口となる機器のアドレス。サブネットマスクはネットワーク部とホスト部の境界を示す値、ブロードキャストアドレスはネットワーク内の全端末宛てのアドレス、ネットワークアドレスはネットワークそのものを表すアドレス。

プロトコル主なポート番号役割

1台のコンピュータ内では複数のアプリケーション(サービス)が同時に通信を行うことがある。これらを区別するためにTCP/IP通信で用いられる番号が「ポート番号」であり、例えばHTTPは80番、HTTPSは443番のように、プロトコルごとに標準的なポート番号が定められている。

DNS(Domain Name System)は、人が覚えやすいドメイン名(例: example.com)と、通信に必要なIPアドレスとを相互に変換する仕組みである。

DHCP(Dynamic Host Configuration Protocol)は、ネットワークに接続する端末に対してIPアドレスなどのネットワーク設定情報を自動的に割り当てる仕組みであり、端末ごとに手動で設定する手間を省くことができる。

プロキシサーバは、クライアントの代理としてインターネット上のサーバへアクセスし、通信の中継やキャッシュの保持、アクセス制御などを行うサーバである。

つまずきやすいポイント DNSは「名前解決(ドメイン名⇔IPアドレス)」、DHCPは「アドレス等の自動割当て」、NATは「アドレスの変換」と役割が似た用語が並ぶため混同しやすい。それぞれ「何を」「どう変換・割当てするか」で整理して区別する。
練習問題 0 / 2問 正解

問1　ネットワークに接続した端末に、IPアドレスなどのネットワーク設定を自動的に割り当てるプロトコルはどれか。

DHCPは、IPアドレス・サブネットマスク・デフォルトゲートウェイなどを自動で割り当てる。DNSはドメイン名とIPアドレスの相互変換(名前解決)、NATはアドレスの変換、SMTPはメールの送信に使う。

問2　HTTPSで通常使われるポート番号はどれか。

HTTPSはSSL/TLSで暗号化したHTTP通信で、ポート番号は443。80はHTTP(平文)、53はDNS、25はSMTPのポート番号。

6ネットワークセキュリティ(暗号化方式とVPN)

方式特徴代表例
共通鍵暗号方式暗号化と復号に同じ鍵を使う。処理が高速だが、鍵の受け渡しに注意が必要。AES, DES
公開鍵暗号方式暗号化用(公開鍵)と復号用(秘密鍵)に異なる鍵を使う。鍵配送は安全だが処理が重い。RSA, 楕円曲線暗号(ECC)

HTTPSは、通信内容を保護するためにSSL/TLSと呼ばれる暗号化技術を利用しており、その内部では公開鍵暗号方式と共通鍵暗号方式が組み合わせて使われている。

つまずきやすいポイント AES・DESは「共通鍵暗号方式」、RSA・楕円曲線暗号(ECC)は「公開鍵暗号方式」に分類される。名称だけで覚えるのではなく、鍵が1つ(共通)か2つ(公開鍵・秘密鍵)かという構造で整理すると区別しやすい。
練習問題 0 / 2問 正解

問1　共通鍵暗号方式に分類される暗号はどれか。

AESは暗号化と復号に同じ鍵を使う共通鍵暗号方式。RSAと楕円曲線暗号は、公開鍵と秘密鍵を使う公開鍵暗号方式。SHA-256はハッシュ関数で、暗号化して元に戻すためのものではない。

問2　インターネットなどの公衆回線上に、暗号化技術を使って仮想的な専用線のような通信経路を作る技術はどれか。

VPN(Virtual Private Network)は、拠点間の接続や在宅勤務時の社内ネットワークへの接続に使われる。NATはアドレスの変換、DHCPはIPアドレスなどの自動割当て、プロキシサーバはクライアントの代理でサーバにアクセスする仕組み。

7電子メールのプロトコル

電子メールは、送信と受信で使うプロトコルが異なる。送信側のメールサーバから相手のメールサーバへの転送にはSMTPを使い、受信者は自分のメールサーバからPOPまたはIMAPでメールを取り出す。

プロトコル用途特徴
SMTP送信・サーバ間の転送メールをメールサーバへ送る。送信時に利用者を認証する仕組みを SMTP-AUTH という
POP3受信メールを端末にダウンロードして読む(基本的にサーバからは削除される)
IMAP4受信メールをサーバ上に置いたまま読む・管理する。複数の端末から同じメールを扱える
MIME形式の拡張日本語や画像などの添付ファイルを電子メールで送れるようにする規格(暗号化・署名を加えたものが S/MIME)
つまずきやすいポイント SMTPは送信、POP・IMAPは受信。スマートフォンとPCの両方で同じ受信メールを見たい場合は、サーバにメールを残すIMAPが向いている。
練習問題 0 / 2問 正解

問1　受信したメールをメールサーバ上に置いたまま読み、スマートフォンとPCなど複数の端末から同じメールを扱えるプロトコルはどれか。

IMAP4はメールをサーバ上で管理するため、複数の端末で同じメールを扱える。POP3はメールを端末にダウンロードして読み、基本的にサーバからは削除される。SMTPは送信とサーバ間の転送、MIMEは日本語や添付ファイルを送るための規格。

問2　電子メールで、日本語の本文や画像などの添付ファイルを送れるようにする規格はどれか。

MIMEは、電子メールで英数字以外のデータを扱えるようにする規格。これに暗号化・署名を加えたものが S/MIME。SMTP-AUTHは送信時に利用者を認証する仕組み、POP3・IMAP4は受信のプロトコル。

8LANの通信制御方式と伝送時間の計算

1本の伝送路を複数の端末で共有するLANでは、送信が重ならないように制御する必要がある。

方式使われるLANしくみ
CSMA/CD有線LAN(イーサネット)伝送路が空いていれば送信し、送信中に衝突(コリジョン)を検出したら、ランダムな時間待って再送する
CSMA/CA無線LAN無線では衝突を検出しにくいため、伝送路が空いていてもランダムな時間待ってから送信し、衝突を回避する
伝送時間の計算 伝送時間(秒) = データ量(ビット) ÷ (回線速度(ビット/秒) × 伝送効率)
※ データ量がバイトで与えられたら、8倍してビットに直す
例題: 100Mバイトのファイルを伝送する時間 回線速度100Mビット/秒、伝送効率80%の回線で100Mバイトのファイルを送る。
データ量 = 100M × 8 = 800Mビット
実効速度 = 100Mビット/秒 × 0.8 = 80Mビット/秒
伝送時間 = 800 ÷ 80 = 10秒
つまずきやすいポイント 回線速度は「ビット/秒(bps)」、ファイルサイズは「バイト」で表されることが多い。1バイト = 8ビットの変換を忘れると答えが8倍ずれる。また伝送効率を掛けると、実際に使える速度は回線速度より遅くなる。
練習問題 0 / 2問 正解

問1　無線LANで使われ、伝送路が空いていてもランダムな時間待ってから送信することで、衝突を回避する通信制御方式はどれか。

無線では衝突を検出しにくいため、CSMA/CA(Collision Avoidance)で衝突を避ける。CSMA/CDは有線LAN(イーサネット)で使われ、衝突を検出したら待って再送する。トークンパッシングは送信権(トークン)を順に回す方式、TDMAは時間を区切って端末ごとに割り当てる方式。

問2　回線速度100Mビット/秒、伝送効率50%の回線で、50Mバイトのファイルを送るのに何秒かかるか。

データ量は 50M × 8 = 400Mビット、実効速度は 100M × 0.5 = 50Mビット/秒なので、400 ÷ 50 = 8 秒。ウは伝送効率を掛け忘れた場合(400 ÷ 100)、イはバイトをビットに直し忘れた場合(50 ÷ 50)、アはその両方を忘れた場合。

9IoTを支える無線通信とネットワーク技術

多数のセンサや機器をネットワークにつなぐIoTでは、用途に合わせた無線通信技術や、処理を分散させる仕組みが使われる。

5G(第5世代移動通信システム)「高速・大容量」「低遅延」「多数同時接続」を特徴とする移動通信の規格
BLE(Bluetooth Low Energy)消費電力を抑えたBluetoothの規格。ウェアラブル機器などに使う
エッジコンピューティングデータを遠くのクラウドに送らず、利用者や機器に近い場所(エッジ)で処理する。通信の遅延や量を減らせる

SDNネットワーク機器の制御機能をソフトウェアに集約し、ネットワーク全体の構成を柔軟に設定・変更できるようにする考え方
つまずきやすいポイント LPWAは「速度は低いが、省電力・広範囲」。高速なのは5G。エッジコンピューティングは「クラウドに集めて処理する」のとは逆に、「現場の近くで処理する」考え方である。

問1　通信速度は低いが、省電力で数km〜数十kmの広い範囲をカバーし、電池で長期間動くIoTのセンサに向く無線通信技術はどれか。

LPWA(Low Power Wide Area)は「省電力・広範囲・低速」が特徴。5Gは高速・大容量・低遅延・多数同時接続の移動通信規格。BLEは省電力だが近距離向けのBluetoothの規格。テザリングはスマートフォンなどを中継器にしてインターネットに接続すること。

問2　データを遠くのクラウドに送らず、利用者や機器に近い場所で処理することで、通信の遅延や量を減らす考え方はどれか。

エッジコンピューティングは、現場の近く(エッジ)で処理して、遅延や通信量を減らす。クラウドコンピューティングはデータをクラウドに集めて処理するので逆の考え方。SDNはネットワーク機器の制御をソフトウェアに集約して構成を柔軟に変える考え方。
