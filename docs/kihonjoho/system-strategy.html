システム戦略のまとめ

情報システム戦略の考え方から、EA・BPR・ERPによる業務最適化、システム調達で使われるRFP/RFI、情報活用を支える仕組み、業務プロセスの改善、e-ビジネス、ソリューションビジネス、IoT・AI・DXといった動向まで、システム戦略で問われる要点を整理しています。読み終えたら下部から問題を解いて定着させましょう。

1情報システム戦略と業務最適化の手法(EA・BPR・ERP)

情報システム戦略とは、経営戦略や事業目標を達成するために、情報システムをどのように整備・活用していくかを定める計画である。個々の業務システムの改善にとどまらず、企業全体を俯瞰して情報システムのあるべき姿を描く点が特徴である。

この情報システム戦略を実現するための代表的な考え方・手法として、エンタープライズアーキテクチャ(EA)・BPR・ERPがある。いずれも部分最適ではなく企業全体の効率化・最適化を目指す点で共通するが、扱っている対象のレベルが異なる。

用語説明
エンタープライズアーキテクチャ(EA)企業全体の業務やシステムを「ビジネス」「データ」「アプリケーション」「技術」の4つの観点から体系的にとらえ、全体最適化を図るための設計手法・考え方
BPR(業務プロセス改革)既存の業務プロセスを部分的な改善にとどめず、抜本的に見直し・再設計することで、業務の効率化・品質向上・コスト削減を図る手法
ERP(統合基幹業務システム)企業の経営資源(ヒト・モノ・カネ・情報)を統合的に管理し、生産・販売・会計・人事など複数の業務プロセスを一元的に扱う手法・システム
つまずきやすいポイント EA・BPR・ERPはいずれも「全体最適化」というキーワードで結び付けて出題されやすいが、対象のレベルが異なる。EAは企業全体を4つの観点から体系的に捉える設計の枠組み、BPRは業務プロセスを抜本的に見直す改革の手法、ERPはヒト・モノ・カネ・情報を一元管理するシステム・仕組みである。名称と役割を対応づけて覚える。
練習問題 0 / 2問 正解

問1　既存の業務プロセスを部分的な改善にとどめず、抜本的に見直して再設計することで、業務の効率や品質を大きく高める手法はどれか。

BPR(業務プロセス改革)は業務のやり方そのものを根本から作り直す。EAは企業全体の業務とシステムを4つの観点で体系化して全体最適を図る手法、ERPは基幹業務を統合的に管理するシステム、RPAは定型的なPC作業をソフトウェアのロボットで自動化するもの。

問2　企業の経営資源を統合的に管理し、生産・販売・会計・人事などの基幹業務を1つのシステムで連携させるものはどれか。

ERPは複数の基幹業務のデータを統合して管理する。SFAは営業活動を記録・共有して効率化するシステム、グループウェアは組織内の情報共有や共同作業を支援するシステム。EAはシステムではなく、企業全体を体系化する手法。

2システム調達における提案依頼(RFPとRFI)

システムを外部のベンダーから調達する際には、発注者(ユーザー企業)側が要求内容を整理し、それを文書としてベンダーに提示するという手順を踏む。この調達プロセスで用いられる代表的な文書がRFI(情報提供依頼書)とRFP(提案依頼書)である。

項目RFI(情報提供依頼書)RFP(提案依頼書)
目的ベンダーが持つ製品・技術・実績などの情報を集める発注者が要求する機能・条件を明確に伝え、提案を依頼する
提示するタイミング調達検討の初期段階(要求がまだ固まっていない)要求内容がある程度固まった段階
ベンダーからの回答製品・技術・実績などの情報・資料要求を満たす具体的な提案書・見積書
つまずきやすいポイント RFIは調達検討の初期段階で、ベンダーが「何を提供できるか」という情報を集めるための文書であるのに対し、RFPは発注者側の要求がある程度固まった段階で、その要求を満たす具体的な提案を依頼する文書である。「情報を集める(RFI)」のか「提案を依頼する(RFP)」のかを、提示するタイミングとセットで覚えると区別しやすい。
練習問題 0 / 2問 正解

問1　システムの調達で、要求内容がある程度固まった段階で、発注者が要求する機能や条件をベンダーに伝えて、具体的な提案を依頼する文書はどれか。

RFP(提案依頼書)を受け取ったベンダーは、提案書や見積書を提出する。RFI(情報提供依頼書)は検討の初期段階で、ベンダーの製品・技術・実績などの情報を集めるための文書。NDAは秘密保持契約。

問2　システムの調達を検討し始めた初期の段階で、ベンダーが持つ製品・技術・実績などの情報を集めるために出す文書はどれか。

RFIは「ベンダーが何を提供できるか」を知るための文書で、要求がまだ固まっていない段階で使う。その情報をもとに要求を固めてから、RFPで具体的な提案を依頼する。見積書はベンダーが発注者に提出するもの。

3情報共有・情報活用を支える仕組み

企業活動を支える情報システムには、人と人との情報共有・共同作業を支援するものと、データを蓄積・分析して経営の意思決定を支援するものがある。

用語説明
グループウェア電子メール・電子掲示板・スケジュール管理などの機能を統合し、組織内の情報共有やメンバー間の共同作業を支援するソフトウェア
データウェアハウス企業内の様々な業務システムから収集・蓄積したデータを、時系列に整理し、経営分析や意思決定に活用しやすい形で統合・格納した大規模なデータベース
BIツール企業に蓄積された大量のデータを分析し、経営上の意思決定に役立つ情報をグラフやレポートの形で可視化するためのツール

一般に、各業務システムから収集したデータをデータウェアハウスに蓄積し、そのデータをBIツールで分析・可視化することで経営判断に役立てる、という流れで用いられる。グループウェアは人同士の情報共有が中心である一方、データウェアハウス・BIツールはデータの蓄積・分析が中心であり、目的が異なる点を押さえておく。

例題: 情報活用の流れ 各店舗のPOSシステムに蓄積された売上データをデータウェアハウスに集約し、BIツールで地域別・商品別の売上傾向を分析してグラフ化した。このように、蓄積・整理されたデータを分析し可視化するのがBIツールの役割である。
練習問題 0 / 2問 正解

問1　企業に蓄積された大量のデータを分析し、経営上の意思決定に役立つ情報をグラフやレポートの形で可視化するツールはどれか。

BIツールはデータウェアハウスなどに蓄積したデータを分析・可視化する。グループウェアは組織内の情報共有を支援するシステム、EDIは企業間で取引データを決められた形式で交換する仕組み。

問2　電子メール・電子掲示板・スケジュール管理などの機能を統合し、組織内の情報共有やメンバー間の共同作業を支援するシステムはどれか。

グループウェアは人と人との情報共有・共同作業を支える。データウェアハウスは業務システムのデータを時系列に整理して蓄積したもの、BIツールはそのデータを分析・可視化するツールで、どちらもデータの活用を支える仕組み。

4先端技術の動向とDX

近年の出題では、IoTや機械学習(AI)といった先端技術と、それらを活用したDX(デジタルトランスフォーメーション)についても問われる。IoT・機械学習は価値創出のための「手段」であり、DXはそれらを活用して事業そのものを変革する「取り組み」である点を意識して整理する。

用語説明
IoT(Internet of Things)家電・自動車・各種センサなど、様々な「モノ」がインターネットに接続され、相互に情報をやり取りする仕組み
機械学習AI(人工知能)を実現する技術の1つであり、大量のデータからコンピュータ自身が規則性やパターンを学習し、未知のデータに対する予測や判断を行えるようにする技術
DX(デジタルトランスフォーメーション)デジタル技術を活用して、製品・サービス・ビジネスモデルや組織文化そのものを変革し、競争上の優位性を確立する取り組み
例題: IoT・機械学習からDXへ 工場の設備にセンサを取り付けて稼働データを収集し(IoT)、蓄積したデータを機械学習で分析して故障の予兆を検知できるようにした。これにより保守業務の在り方そのものを見直すことができれば、それはDXの一例といえる。IoT・機械学習は手段、DXはそれによってもたらされる事業・組織の変革である。
練習問題 0 / 2問 正解

問1　DX(デジタルトランスフォーメーション)の説明として、適切なものはどれか。

DXは、デジタル技術で事業や組織のあり方そのものを変えること。アの電子化やイの機器の更新、ウのRPAによる自動化は、それだけではDXとはいえない(DXを進める手段の一部にはなりうる)。

問2　家電・自動車・各種センサなど、さまざまな「モノ」がインターネットに接続され、相互に情報をやり取りする仕組みはどれか。

IoT(Internet of Things)でモノから集めたデータを、機械学習で分析して故障の予兆を検知するなど、組み合わせて使われることが多い。機械学習はデータから規則性を学ぶAIの技術。

5業務プロセスの可視化と改善(BPMN・BPM・RPA)

業務を改善するには、まず現状の業務の流れを図にして(可視化して)問題点を見つけ、改善し続ける仕組みを回していく。

用語説明
BPMN業務プロセスの流れを、イベント(丸)・アクティビティ(角丸の四角)・分岐(ひし形)などの記号で表す表記法
BPM(ビジネスプロセスマネジメント)業務プロセスを分析・設計・実行・評価するPDCAサイクルを回し、継続的に改善していく管理手法(一度に抜本的に作り直すBPRとの違いに注意)
RPA人がPCで行っている定型的な事務作業(データの転記・集計など)を、ソフトウェアのロボットで自動化する
SFA(営業支援システム)営業担当者の活動や商談の進み具合を記録・共有し、営業活動を効率化する
ワークフローシステム申請・承認などの手続きを電子化し、決められた経路で書類を回す
つまずきやすいポイント RPAは「人が行う定型的なPC操作をそのまま自動化する」もので、業務プロセス自体を見直すBPRとは異なる。またBPMは「継続的な改善」、BPRは「抜本的な改革」と対比して覚える。
練習問題 0 / 2問 正解

問1　人がPCで行っているデータの転記や集計などの定型的な事務作業を、ソフトウェアのロボットで自動化するものはどれか。

RPAは人の操作をそのまま自動化するもので、業務プロセス自体を見直すBPRとは異なる。BPMは業務プロセスのPDCAを回して継続的に改善する管理手法、BPMNは業務の流れを図で表す表記法。

問2　業務プロセスを分析・設計・実行・評価するPDCAサイクルを回し、継続的に改善していく管理手法はどれか。

BPM(ビジネスプロセスマネジメント)は「継続的な改善」の仕組み。BPRは一度に抜本的に作り直す改革で、BPMNは業務の流れをイベント・アクティビティ・分岐などの記号で表す表記法。

6e-ビジネス(電子商取引・EDI・ロングテール)

インターネットを使った商取引(電子商取引、EC)は、取引の当事者の組み合わせで分類される。

分類取引の当事者例
BtoB企業と企業企業間の部品の受発注、電子調達
BtoC企業と消費者ネットショッピング、オンラインバンキング
CtoC消費者と消費者ネットオークション、フリマアプリ
BtoE / GtoC企業と従業員 / 行政と市民社員向け販売 / 電子申請
用語説明
EDI(電子データ交換)企業間の受発注などの取引データを、決められた形式(標準の規約)で通信回線を通じて交換する
ロングテールネット販売では在庫や陳列の制約が小さいため、個々の売上は少ないニッチ商品の売上を積み重ねることで大きな売上を得られるという考え方
O2O(Online to Offline)クーポン配信など、ネット上(オンライン)の情報で実店舗(オフライン)への来店や購買を促す
オムニチャネル実店舗・ECサイト・アプリなど、あらゆる販売経路を統合して、どこからでも同じように購入できるようにする
エスクローサービス売り手と買い手の間に第三者が入り、代金を一時的に預かって、商品が届いてから売り手に支払う仕組み
フィンテック(FinTech)金融(Finance)と技術(Technology)を組み合わせた新しい金融サービス(スマホ決済など)
つまずきやすいポイント ロングテールは「売れ筋商品(ヘッド)ではなく、少しずつしか売れない多数の商品(テール)の合計が大きくなる」という話である。パレートの法則(売上の大部分は一部の商品が生む)とは逆の見方になる。
練習問題 0 / 2問 正解

問1　ネットオークションやフリマアプリのように、消費者と消費者の間で行われる電子商取引はどれか。

CtoCは消費者どうしの取引。BtoBは企業間の取引(部品の受発注など)、BtoCは企業と消費者の取引(ネットショッピングなど)、GtoCは行政と市民の間のサービス(電子申請など)。

問2　ネット販売では在庫や陳列の制約が小さいため、個々の売上は少ないニッチな商品の売上を積み重ねることで、大きな売上を得られるという考え方はどれか。

ロングテールは、売れ筋(ヘッド)ではなく、少しずつしか売れない多数の商品(テール)の合計が大きくなるという考え方。O2Oはネット上の情報で実店舗への来店を促すこと、オムニチャネルはあらゆる販売経路を統合すること、エスクローサービスは第三者が代金を一時的に預かる仕組み。

7ソリューションビジネスと情報システム化計画

顧客の経営課題を解決するため、ハードウェア・ソフトウェア・サービスを組み合わせて提供するビジネスをソリューションビジネスという。自社でシステムを持たず、外部のサービスや資源を利用する形態も増えている。

用語説明
SOA(サービス指向アーキテクチャ)業務の機能を「サービス」という部品として作り、それらを組み合わせてシステムを構築する考え方
アウトソーシング業務の一部または全部を外部の専門業者に委託する
BPO(ビジネスプロセスアウトソーシング)経理・人事などの業務プロセスをまるごと外部に委託する
ハウジングサービス事業者の施設に、利用者が自分のサーバを設置させてもらう
ホスティングサービス事業者が用意したサーバを、利用者が借りて使う
オンプレミスサーバやソフトウェアを自社の設備内に設置・運用する(クラウドとの対比で使う)

システム化を進める際は、経営戦略に基づいて情報システム戦略を立て、それを実現するために個々のシステムの「情報システム化計画」を作る。計画では、システム化の目的・範囲・スケジュール・費用と、導入によって得られる効果(投資対効果)を明らかにする。

つまずきやすいポイント ハウジングとホスティングは「サーバが誰のものか」で区別する。ハウジングは場所(設備)だけを借り、サーバは自分で持ち込む。ホスティングはサーバごと借りる。
練習問題 0 / 2問 正解

問1　事業者の施設(データセンタなど)に、利用者が自分で用意したサーバを設置させてもらうサービスはどれか。

ハウジングは場所(設備)だけを借り、サーバは利用者が持ち込む。ホスティングは事業者が用意したサーバを借りる。オンプレミスはサーバを自社の設備内に設置・運用すること。

問2　経理や人事などの業務プロセスを、まるごと外部の専門業者に委託することはどれか。

BPO(ビジネスプロセスアウトソーシング)は業務プロセスをまるごと委託する、アウトソーシングの一形態。SOAは業務の機能を「サービス」という部品として作り、組み合わせてシステムを構築する考え方。
