コンピュータ構成要素のまとめ

コンピュータの5大装置・CPUの仕組み・アドレス指定方式・割り込みとDMA・記憶階層・補助記憶装置と入出力インタフェースなど、コンピュータ構成要素で問われる要点を図解しています。読み終えたら下部から問題を解いて定着させましょう。

1コンピュータの基本構成(5大装置)

コンピュータは「入力装置・出力装置・記憶装置・演算装置・制御装置」の5大装置から構成される。このうち演算装置と制御装置をあわせて中央処理装置(CPU)と呼ぶ。

装置役割
入力装置キーボード・マウス・スキャナなど、データを取り込む
出力装置ディスプレイ・プリンタなど、処理結果を出力する
記憶装置プログラムやデータを記憶する(主記憶・補助記憶)
演算装置四則演算・論理演算などデータの処理を行う
制御装置各装置に指示を出し、プログラムの実行を制御する
つまずきやすいポイント 5大装置は「入力・出力・記憶・演算・制御」の5つであり、「通信装置」は含まれない(頻出のひっかけ)。また演算装置と制御装置をあわせたものがCPU(中央処理装置)である。
練習問題 0 / 2問 正解

問1　コンピュータの5大装置に含まれないものはどれか。

5大装置は「入力装置・出力装置・記憶装置・演算装置・制御装置」の5つで、通信装置は含まれない。

問2　中央処理装置(CPU)を構成する装置の組合せとして、適切なものはどれか。

CPUは、データの処理を行う演算装置と、各装置に指示を出してプログラムの実行を制御する制御装置をあわせたもの。記憶装置(主記憶・補助記憶)はCPUとは別の装置として数える。

2CPUの高速化技術(クロック・パイプライン・マルチコア)

CPUの動作はクロック信号に同期して行われる。1秒間のクロック信号の回数を表す単位がクロック周波数(Hz)であり、数値が大きいほど一般に処理速度は高い。実際の処理速度はクロック周波数だけでなく、1命令の実行に必要なクロック数(CPI)や並列処理の仕組みにも左右される。

クロック周期と命令実行時間 クロック周期(秒) = 1 ÷ クロック周波数(Hz)
1命令の実行時間 = CPI(1命令あたりの平均クロック数) × クロック周期
例題: クロック周波数2GHz、CPI=4のときの1命令の実行時間 クロック周期 = 1 ÷ (2×10⁹) = 0.5ナノ秒
実行時間 = 4 × 0.5ナノ秒 = 2ナノ秒

命令の実行は「取り出し(IF)→解読(ID)→実行(EX)→記憶アクセス(MEM)→書き戻し(WB)」のような段階に分けられる。これらの段階を1命令ずつ順番に処理するのではなく、複数の命令の各段階を少しずつずらして同時並行に処理する方式をパイプライン処理と呼び、スループット(単位時間あたりの処理数)を向上させる。

近年は1つのCPUパッケージ内に複数の処理コアを搭載するマルチコアプロセッサも普及しており、複数の処理を並列に実行することで性能向上を図っている。

つまずきやすいポイント クロック周波数が高い=必ず処理が速いとは限らない(CPIやアーキテクチャの違いで実際の性能は変わる)。同様に、コア数がN倍になっても性能が単純にN倍になるとは限らない(並列化できない処理も含まれるため)。
練習問題 0 / 2問 正解

問1　クロック周波数が4GHzで、1命令あたりの平均クロック数(CPI)が2のCPUの、1命令の平均実行時間は何ナノ秒か。

クロック周期は 1 ÷ (4 × 10⁹) = 0.25ナノ秒。1命令の実行時間は CPI × クロック周期 = 2 × 0.25 = 0.5ナノ秒。アはクロック周期をCPIで割った値、ウは周波数をCPIで割った値(4 ÷ 2)、エは周波数とCPIを掛けた値で、いずれも式の使い方を誤っている。

問2　CPUのパイプライン処理の説明として、適切なものはどれか。

パイプライン処理では、ある命令が解読段階に進むと同時に次の命令の取り出しを始めるなど、段階をずらして重ねることで全体の処理時間を短くする。イはマルチコア、エはキャッシュメモリの説明。

3記憶階層(レジスタ・キャッシュメモリ・主記憶)

CPUに近い記憶装置ほど高速・小容量・高コストであり、遠い記憶装置ほど低速・大容量・低コストになる。この階層構造を記憶階層と呼ぶ。

種類特徴
SRAMリフレッシュ不要、高速だが高価・小容量。主にキャッシュメモリに使用
DRAMリフレッシュ動作が必要な揮発性メモリ。安価・大容量で主記憶に使用
ROM読み出し専用で電源を切っても内容が消えない不揮発性メモリ
RAM読み書き可能なメモリの総称(電源を切ると内容が消える揮発性が一般的)
実効アクセス時間(キャッシュのヒット率を考慮) 実効アクセス時間 = ヒット率 × キャッシュのアクセス時間 + (1 − ヒット率) × 主記憶のアクセス時間
例題: キャッシュ10ns、主記憶100ns、ヒット率90%のときの実効アクセス時間 実効アクセス時間 = 0.9 × 10ns + 0.1 × 100ns = 9ns + 10ns = 19ns
つまずきやすいポイント SRAM(高速・高価・小容量、リフレッシュ不要)とDRAM(低速・安価・大容量、リフレッシュ必要)を混同しない。ROMは「読み出し専用の不揮発性メモリ」であり、書き込み可能なRAMとは性質が異なる。
練習問題 0 / 2問 正解

問1　キャッシュメモリのアクセス時間が5ナノ秒、主記憶のアクセス時間が50ナノ秒、キャッシュのヒット率が80%のとき、実効アクセス時間は何ナノ秒か。

実効アクセス時間 = 0.8 × 5 + (1 − 0.8) × 50 = 4 + 10 = 14ナノ秒。ウはヒット率を主記憶の側に掛けてしまった場合(0.2 × 5 + 0.8 × 50)。アはキャッシュの分だけ、エは2つのアクセス時間を単純に足した値。

問2　リフレッシュ動作が必要な揮発性のメモリで、安価で大容量にしやすいため主記憶に使われるものはどれか。

DRAMはリフレッシュが必要だが安価・大容量で、主記憶に使われる。SRAMはリフレッシュ不要で高速だが高価・小容量のため、キャッシュメモリに使われる。ROMは読み出し専用の不揮発性メモリ、レジスタはCPU内部にある最も高速・小容量の記憶装置。

4補助記憶装置と入出力インタフェース

補助記憶装置は電源を切っても内容が消えない不揮発性の記憶装置で、主記憶よりも低速だが大容量・低コストである。代表例としてHDD(磁気ディスク)とSSD(半導体メモリ)がある。

装置特徴
HDD磁気ディスクを回転させ、磁気ヘッドでデータを読み書きする。駆動部分(可動部品)を持つ
SSD半導体メモリを用いる。駆動部分を持たず、HDDより衝撃・振動に強く、動作音も静か

周辺機器とパソコンを接続するインタフェースの規格もよく問われる。USBはパソコンと周辺機器を接続する代表的なシリアルインタフェース規格であり、キーボード・マウス・プリンタなど幅広い機器で利用される。

機器の分類例
入力装置キーボード、マウス、スキャナ
出力装置ディスプレイ、プリンタ
つまずきやすいポイント SSDは半導体メモリを用いるため、HDDのような磁気ヘッドは持たない(磁気ヘッドを使うのはHDDの特徴)。「可動部品がない」= 衝撃・振動に強いという因果関係もあわせて押さえる。
練習問題 0 / 2問 正解

問1　SSDの特徴として、適切なものはどれか。

SSDは半導体メモリを使う不揮発性の補助記憶装置で、可動部品がないため衝撃・振動に強く、動作音も静か。アはHDDの特徴。補助記憶装置は電源を切っても内容が消えず(イは誤り)、主記憶より低速・大容量・低コスト(ウは誤り)。

問2　次の機器のうち、入力装置に分類されるものはどれか。

スキャナは紙の文書や写真を読み取ってデータとして取り込む入力装置。ディスプレイとプリンタは出力装置、SSDは補助記憶装置。

5命令の実行とアドレス指定方式・MIPS

CPUは主記憶から命令を1つずつ取り出して実行する。命令は「何をするか」を表す命令部(オペコード)と、「どのデータを使うか」を表すアドレス部(オペランド)からなる。アドレス部の値から実際にデータがある場所(有効アドレス)を求める方法をアドレス指定方式という。

方式有効アドレス(データの場所)の求め方
即値アドレス指定アドレス部の値そのものがデータ(主記憶を参照しない)
直接アドレス指定アドレス部の値がそのまま有効アドレス
間接アドレス指定アドレス部が指す番地に入っている値が有効アドレス
インデックス(指標)アドレス指定アドレス部の値 + インデックスレジスタの値
ベースアドレス指定アドレス部の値 + ベースレジスタの値
相対アドレス指定アドレス部の値 + プログラムカウンタの値
例題: アドレス部が100のとき、それぞれの方式で使われるデータ 主記憶の100番地に150、150番地に25が入っているとする。
即値: 100そのもの / 直接: 100番地の値 150 / 間接: 100番地の値150を番地とみなし、150番地の値 25
MIPS(1秒間に実行できる命令数を百万単位で表した性能指標) MIPS = 1秒 ÷ 1命令の平均実行時間 ÷ 10⁶
(1命令の平均実行時間 = CPI × クロック周期。「CPUの高速化技術」の節を参照)
例題: 1命令の平均実行時間が20ナノ秒のCPUの性能 1秒 ÷ (20 × 10⁻⁹秒) = 5 × 10⁷ 命令/秒 → 5 × 10⁷ ÷ 10⁶ = 50MIPS
つまずきやすいポイント 間接アドレス指定は主記憶を2回参照する(1回目で番地を得て、2回目でデータを得る)。MIPS値は大きいほど高性能だが、命令の種類(1命令の重さ)が違うCPUどうしでは単純に比べられない。
練習問題 0 / 2問 正解

問1　命令のアドレス部の値が200で、主記憶の200番地に300、300番地に40が格納されている。間接アドレス指定方式のとき、命令で使われるデータはどれか。

間接アドレス指定では、アドレス部が指す200番地の値(300)を有効アドレスとみなし、300番地の値 40 を使う(主記憶を2回参照する)。イは即値アドレス指定、ウは直接アドレス指定の場合のデータ。エは値を足し合わせたもので、間接アドレス指定では足し算はしない。

問2　1命令の平均実行時間が25ナノ秒のCPUの性能は何MIPSか。

1秒間に実行できる命令数は 1 ÷ (25 × 10⁻⁹) = 4 × 10⁷ 命令。百万(10⁶)単位にすると 40MIPS。アとエは10の累乗の計算を1桁ずつ誤った値、イは平均実行時間の数値をそのまま使った値。

6割り込みとDMA

割り込みは、実行中のプログラムを一時中断して、発生した事象に対応する処理(割り込み処理)を先に行い、終わったら元のプログラムに戻る仕組みである。原因がCPUの外にあるか、実行中のプログラムにあるかで2つに分けられる。

種類原因の例
外部割り込み入出力の完了、タイマ(一定時間の経過)、電源異常、機械の故障(マシンチェック)
内部割り込みゼロでの除算やオーバフローなどのプログラムの誤り、存在しないページへのアクセス(ページフォールト)、プログラムからOSの機能を呼び出す命令(SVC)

入出力装置と主記憶の間のデータ転送を、CPUを介さずに専用の制御装置(DMAコントローラ)が直接行う方式をDMA(Direct Memory Access)という。転送中もCPUは別の処理を進められ、転送が終わるとDMAコントローラが割り込みでCPUに知らせる。

つまずきやすいポイント ゼロ除算やページフォールトは、実行中のプログラム自身が原因なので「内部割り込み」。入出力の完了やタイマは、プログラムの外で起きることなので「外部割り込み」。DMAは「CPUの負担を減らす転送方式」であり、転送そのものをCPUが行うプログラム制御方式とは異なる。
練習問題 0 / 2問 正解

問1　内部割り込みに分類されるものはどれか。

ゼロでの除算は、実行中のプログラム自身が原因で起きるので内部割り込み。タイマ・入出力の完了・電源異常は、プログラムの外で起きる事象なので外部割り込み。

問2　入出力装置と主記憶の間のデータ転送を、CPUを介さずに専用の制御装置が直接行う方式はどれか。

DMA(Direct Memory Access)では、DMAコントローラが転送を行うため、その間もCPUは別の処理を進められる。割り込みは実行中の処理を中断して別の処理を先に行う仕組み、パイプラインは命令を段階的に重ねて処理する技術、キャッシュメモリは主記憶へのアクセスを速くするための高速なメモリ。
