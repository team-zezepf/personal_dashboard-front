ハードウェアのまとめ

記憶装置・入出力装置・センサ/アクチュエータなど、ハードウェアを構成する基本要素の特徴を図解しています。読み終えたら下部から問題を解いて定着させましょう。

1記憶装置(半導体メモリ・HDD/SSD・RAID)

半導体メモリには、電源を切るとデータが消える「揮発性」のものと、電源を切ってもデータが保持される「不揮発性」のものがある。用途によって使い分けられている。

メモリ種別揮発性特徴
DRAM揮発性コンデンサに電荷を蓄えて記憶する。定期的な再書き込み(リフレッシュ)が必要。主記憶装置に使用
SRAM揮発性フリップフロップ回路で記憶する。リフレッシュ不要で高速だが高コスト。キャッシュメモリに使用
ROM不揮発性読み出し専用として利用される(一部、電気的に書換え可能なものもある)
フラッシュメモリ不揮発性電気的にデータの消去・書き込みが可能。電源を切ってもデータを保持する。SSDやUSBメモリなどに使用
比較項目HDDSSD
記憶媒体磁気ディスク(駆動部分あり)半導体メモリ(駆動部分なし)
読み書き速度比較的遅い比較的速い
耐衝撃性可動部があるため劣る優れる
容量単価(1GBあたり)一般に安い一般に高い
つまずきやすいポイント HDDとSSDの比較問題では「速度」「耐衝撃性」「容量単価」の優劣が入れ替えられて出題されやすい。「HDDは可動部品を持ち低コスト、SSDは駆動部分がなく高速・耐衝撃だが単価は高い」という対応をセットで覚えること。

RAID(Redundant Arrays of Inexpensive Disks)は、複数の磁気ディスク装置を組み合わせて1台の論理的な装置のように扱う技術である。データを分散して書き込むことで高速化を図ったり、同じデータを複数台に記録することで耐障害性を高めたりする。

RAIDレベル方式特徴
RAID0(ストライピング)データを分散して複数ディスクに書き込む読み書きが高速化するが冗長性はなく、1台故障すると全データが失われる
RAID1(ミラーリング)同じデータを複数ディスクに複製して書き込む耐障害性が高いが、実効容量はディスク合計より少なくなる
RAID5データと誤り訂正用のパリティを分散して記録1台の故障までは復旧可能。速度と耐障害性のバランスがよい
練習問題 0 / 2問 正解

問1　同じデータを複数のディスクに複製して書き込み、耐障害性を高めるRAIDのレベルはどれか。

RAID1(ミラーリング)は同じデータを複製して書き込むので、1台が故障してもデータが残る。ただし実効容量はディスク合計より少なくなる。RAID0(ストライピング)はデータを分散して書き込むだけで冗長性はない。RAID5はデータとパリティを分散して記録する。RAID10はRAID1とRAID0を組み合わせたもの。

問2　フラッシュメモリの説明として、適切なものはどれか。

フラッシュメモリは不揮発性の半導体メモリで、SSDやUSBメモリに使われる。アはDRAM、イはSRAMの説明で、どちらも電源を切るとデータが消える揮発性メモリ。エはHDDの説明。

2入出力装置とディスプレイ

コンピュータの入出力装置は、人や外部環境とのデータのやり取りを担う。データを取り込む「入力装置」、データを出し出力する「出力装置」、両方を兼ねる「入出力装置」に大別できる。

分類装置例説明
入力装置キーボード、マウス、スキャナ外部からデータを取り込む装置
出力装置ディスプレイ、プリンタ、プロッタ、3Dプリンタデータを外部へ出力する装置(3Dプリンタは3D設計データをもとに材料を層状に積み重ねて立体物を造形する)
入出力装置タッチパネルディスプレイに指やペンで触れることで入力もできる、入力と出力を兼ねた装置
タッチパネル: 画面に指やペンで直接触れて入力
トラックボール: 固定された球を転がしてポインタを操作
ジョイスティック: レバーを倒して方向・位置を入力
ライトペン: ペン先を画面に当てて位置を検出
つまずきやすいポイント 「解像度」(画素の密度)、「リフレッシュレート」(1秒間に画面を書き換える回数)、「コントラスト比」(最も明るい部分と暗い部分の差)、「応答速度」(画素の色が変化する速さ)は、いずれもディスプレイの性能を表す別の指標であり混同しやすい。画素の“数・密度”を表す用語は解像度だけである。
練習問題 0 / 2問 正解

問1　ディスプレイの性能を表す指標のうち、1秒間に画面を書き換える回数を表すものはどれか。

リフレッシュレートが高いほど、動きのある映像がなめらかに表示される。解像度は画素の密度(きめ細かさ)、コントラスト比は最も明るい部分と暗い部分の比、画素数は画面を構成する点の数。

問2　入力と出力を兼ねた装置はどれか。

タッチパネルは画面に表示(出力)しつつ、指やペンで触れて入力もできる。プロッタと3Dプリンタは出力装置、スキャナは入力装置。

3センサとアクチュエータ

センサとアクチュエータは、コンピュータ(制御装置)と物理世界とを結ぶ装置であり、組み込みシステムやIoT機器で対になって使われることが多い。変換する向きが正反対である点が重要である。

検出する物理量センサの例
温度温度センサ
湿度湿度センサ
光量光センサ(照度センサ)
圧力圧力センサ
つまずきやすいポイント センサとアクチュエータは変換の向きが逆である。センサは「物理量→電気信号」(入力装置)、アクチュエータは「電気信号→機械的な運動」(出力装置)。名称と働きを取り違えないよう注意する。
練習問題 0 / 2問 正解

問1　制御装置からの電気信号を、回転や振動などの機械的な動きに変換する装置はどれか。

アクチュエータは「電気信号 → 機械的な動き」に変換する出力側の装置で、モータなどが代表例。センサは逆に「物理量 → 電気信号」に変換する入力側の装置。

問2　照度センサが検出する物理量はどれか。

照度センサ(光センサ)は明るさ(光の量)を検出し、画面の明るさの自動調整などに使われる。温度は温度センサ、湿度は湿度センサ、圧力は圧力センサで検出する。

4処理装置と近距離無線通信

コンピュータの主要な処理装置には、汎用的な処理を順に実行するCPUのほか、特定の処理に特化した専用の処理装置がある。

項目CPUGPU
得意な処理複雑な条件分岐を含む汎用的な処理を順に実行同種の演算を大量のデータに並列に実行(画像処理向き)
コア数少数の高性能なコア多数の単純な演算コア
主な用途OSの制御、アプリケーションの実行など全般画像処理・グラフィックス描画、機械学習の演算など

近距離無線通信にはいくつかの規格があり、通信できる距離や用途によって使い分けられる。

技術通信距離の目安特徴
NFC数cm〜10cm程度ICカードやスマートフォンなどをかざすだけで通信できる近距離無線通信技術。交通系ICカードや決済などに利用
Bluetooth数m〜数十m程度ヘッドホンやマウスなど周辺機器の無線接続に広く利用
Wi-Fi数十m程度(屋内)無線LANとしてネットワークへの接続に利用
赤外線通信数m程度(見通し内)赤外線を使った通信。家電のリモコンなどに利用
つまずきやすいポイント NFCは「かざすだけ」で通信できる極めて近距離(数cm程度)の技術である点が最大の特徴。Bluetooth・Wi-Fiなど他の無線通信技術との通信距離の違いが問われやすいので、距離の大小関係(NFC < Bluetooth < Wi-Fi)を押さえておく。
練習問題 0 / 2問 正解

問1　多数の単純な演算コアを持ち、同じ種類の演算を大量のデータに並列に実行することが得意で、画像処理や機械学習に使われる処理装置はどれか。

GPUは並列演算が得意。CPUは少数の高性能なコアで、複雑な条件分岐を含む汎用的な処理を順に実行するのが得意。DRAMは記憶装置、NFCは近距離無線通信の技術。

問2　ICカードやスマートフォンを、数cm程度の距離にかざすだけで通信できる技術はどれか。

NFCは数cm〜10cm程度の極めて近い距離で通信する技術で、交通系ICカードや決済に使われる。Bluetoothは数m〜数十m程度で周辺機器の接続に、Wi-Fiは無線LANとしてネットワークへの接続に、赤外線通信は家電のリモコンなどに使われる。
