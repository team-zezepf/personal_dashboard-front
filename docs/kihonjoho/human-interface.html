ヒューマンインタフェースのまとめ

GUI・CUIなどインタフェースの種類、ユーザビリティ・アクセシビリティといった使いやすさに関する概念、メニューの種類、インタフェース設計の原則を整理しています。読み終えたら下部から問題を解いて定着させましょう。

1インタフェースの種類(GUI・CUIなど)

人がコンピュータを操作する方法(インタフェース)にはいくつかの種類があり、それぞれ操作のしやすさや対象とする利用者が異なる。基本情報技術者試験では、代表的な方式の名称と特徴をセットで覚えておく必要がある。

方式特徴
GUI(Graphical User Interface)アイコン・ウィンドウ・マウスなどを用いて視覚的・直感的に操作するインタフェース
CUI(Character User Interface)/CLIキーボードからコマンド(文字列)を入力して操作するインタフェース
VUI(Voice User Interface)音声による指示でコンピュータを操作するインタフェース
NUI(Natural User Interface)タッチやジェスチャーなど、人間の自然な動作で操作するインタフェース
つまずきやすいポイント CUIとCLI(Command Line Interface)はほぼ同じ意味で使われ、どちらもコマンド入力による操作を指す。GUIの構成要素(ウィンドウ・アイコン・メニュー・ポインタ)と、CUIの操作方法(文字列コマンドの入力)を対比して覚えると区別しやすい。

2ユーザビリティ・アクセシビリティ・ユニバーサルデザイン

ヒューマンインタフェースでは「誰にとって、どれだけ使いやすいか」という観点から複数の概念が使い分けられる。ユーザビリティは使いやすさの度合いそのものを指すのに対し、アクセシビリティは利用できる人の幅広さに着目した概念である点が異なる。

用語意味
ユーザビリティソフトウェアやWebサイトなどについて、利用者にとっての使いやすさ・分かりやすさ(使用性)を表す概念
アクセシビリティ高齢者や障がいのある人を含む、より多くの人が同様に情報やサービスを利用できることを表す概念
ユニバーサルデザイン年齢・身体的特徴・障がいの有無などにかかわらず、できるだけ多くの人が利用しやすいように製品や環境を設計する考え方
JIS X 8341-3高齢者・障がい者等配慮設計指針として、Webコンテンツのアクセシビリティに関する要件を定めた日本の規格
つまずきやすいポイント ユーザビリティは「使いやすさの度合い」、アクセシビリティは「利用できる人の広さ」、ユニバーサルデザインは「多くの人が使えるように最初から設計する考え方」という視点の違いを意識する。JIS X 8341-3はこのうちアクセシビリティ(特にWeb)を対象とした日本の規格である。

3入力方式とメニューの種類

利用者がコンピュータへ指示を与える方法にはいくつかの方式があり、目的や利用者の習熟度に応じて使い分けられる。あらかじめ用意された選択肢から選ぶメニュー選択方式は、コマンドを暗記する必要がなく、初心者でも扱いやすいという特徴をもつ。

メニューの種類特徴
メインメニュー画面上部などに常時表示される、基本的な操作項目の一覧
プルダウンメニューメニュー項目をクリックすると、下方向に選択肢が展開表示されるメニュー
コンテキストメニュー右クリックなどの操作によって呼び出され、現在選択している対象や状況に応じた操作項目を一覧表示するメニュー
ツールバーよく使う機能をアイコンなどでまとめて配置した操作領域
つまずきやすいポイント コンテキストメニューは「右クリックなどで呼び出され、状況に応じた項目が表示される」点が特徴である。常時画面上部に固定表示されるメインメニューや、クリックで一定の選択肢が開くプルダウンメニューとは表示のきっかけが異なる点で区別する。

4インタフェース設計の原則とデザイン手法

使いやすいインタフェースを実現するには、利用者の操作に対して結果を分かりやすく伝える設計原則や、利用環境に応じて表示を最適化する設計手法が用いられる。

例: フィードバックの具体例 ボタンを押すと色が変化する、処理中にプログレスバーを表示する、送信完了時にメッセージを表示するなど、利用者の操作に対して結果を速やかに伝える仕組みは、いずれもフィードバックの一例である。
デザイン手法特徴
レスポンシブデザインパソコン・タブレット・スマートフォンなど、閲覧するデバイスの画面サイズに応じてWebページのレイアウトを自動的に最適化する設計手法
フラットデザイン影やグラデーションなどの立体的な装飾を排し、平面的でシンプルな表現を用いるデザイン手法
マテリアルデザイン現実の紙のような質感や奥行き・影の表現を取り入れたデザイン手法
ユニバーサルデザイン画面サイズではなく、年齢・身体的特徴・障がいの有無などにかかわらず、誰もが利用しやすいように設計する考え方
つまずきやすいポイント レスポンシブデザインは「画面サイズという利用環境への対応」、ユニバーサルデザインは「利用者の年齢・身体的特徴などにかかわらず誰もが使えるようにする設計思想」であり、着目している対象が異なる。選択肢として並んだときに混同しないよう注意する。
