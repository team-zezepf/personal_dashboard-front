決算整理のまとめ

経過勘定・減価償却・貸倒引当金・売上原価の算定など、決算にあたって行う各種の整理仕訳の考え方と計算方法を、具体的な数値例とともに整理しています。読み終えたら下部から問題を解いて定着させましょう。

1経過勘定(前払・前受・未払・未収)と再振替仕訳

一会計期間の損益を正しく計算するため、決算日を基準に「当期に属する費用・収益」と「次期に属する費用・収益」を区別し直す手続きを経過勘定の整理と呼ぶ。すでに支払い・受け取りが済んでいるが期間がずれている場合を繰延べ(前払・前受)、まだ支払い・受け取りが済んでいないが当期分がすでに発生している場合を見越し(未払・未収)という。

区分内容勘定の性質決算整理仕訳の向き
前払費用次期分の費用をすでに支払っている資産(前払保険料など)費用を減らし、資産を増やす
前受収益次期分の収益をすでに受け取っている負債(前受家賃など)収益を減らし、負債を増やす
未払費用当期分の費用がまだ未払いである負債(未払利息など)費用を増やし、負債を増やす
未収収益当期分の収益がまだ未収である資産(未収利息など)収益を増やし、資産を増やす
例題: 前受収益(受取家賃120,000円のうち次期分30,000円) 決算整理前の受取家賃勘定の残高が120,000円(1年分を前受けしていた)であり、このうち次期分が30,000円含まれている場合
決算整理仕訳: (借)受取家賃 30,000 (貸)前受家賃 30,000
受取家賃(収益)を30,000円減らし、前受家賃(負債)として次期に繰り延べる。
例題: 前払費用(前払保険料15,000円)と翌期首の再振替仕訳 決算にあたり、保険料の前払分15,000円を計上する場合
決算整理仕訳: (借)前払保険料 15,000 (貸)保険料 15,000
翌期首の再振替仕訳: (借)保険料 15,000 (貸)前払保険料 15,000
再振替仕訳によって、前払保険料(資産)をいったん取り崩し、翌期の費用(保険料)として計上し直す。
例題: 未払費用(未払利息9,000円) 借入金の利息(年12,000円、後払い)のうち、決算日までに発生しているが未払いの分が9,000円ある場合
決算整理仕訳: (借)支払利息 9,000 (貸)未払利息 9,000
未払利息(負債)を計上し、まだ支払っていなくても当期の費用として認識する。
例題: 未収収益(未収利息6,000円) 貸付金の利息のうち、決算日までに発生しているが未収の分が6,000円ある場合
決算整理仕訳: (借)未収利息 6,000 (貸)受取利息 6,000
未収利息(資産)を計上し、まだ受け取っていなくても当期の収益として認識する。
つまずきやすいポイント 前払・前受(繰延べ)と未払・未収(見越し)の方向を混同しない。前払費用・未収収益は資産、前受収益・未払費用は負債である。また経過勘定は翌期首に必ず再振替仕訳を行い、決算整理仕訳と貸借を逆にして元の費用・収益勘定に振り戻す点を忘れないこと。
練習問題 0 / 3問 正解

問1　決算にあたり、当期に支払った保険料24,000円のうち8,000円が次期分であったので、前払分を計上する。

次期分の8,000円を保険料(費用)から減らし、前払保険料(資産)として次期に繰り延べる。

問2　決算にあたり、貸付金の利息のうち当期分4,000円がまだ受け取れていないので、これを計上する。

まだ受け取っていなくても当期分の利息は当期の収益とし、受け取る権利である未収利息(資産)を計上する(見越し)。

問3　期首にあたり、前期末に計上した前払保険料8,000円について再振替仕訳を行う。

再振替仕訳は決算整理仕訳の貸借を逆にしたもの。前払保険料を取り崩し、当期の費用(保険料)に戻す。

2減価償却(定額法・直接法と間接法)

建物や備品などの固定資産は、使用や時の経過によって価値が減少していく。この価値の減少分を、決算にあたって費用として計上する手続きを減価償却と呼ぶ。3級でよく出題されるのは、毎期均等額を費用計上する定額法である。

定額法による年間減価償却費 (取得原価 − 残存価額) ÷ 耐用年数 = 減価償却費(1年あたり)
例題: 取得原価600,000円、残存価額0円、耐用年数6年 年間減価償却費 = (600,000円 − 0円) ÷ 6年 = 100,000円
間接法による仕訳: (借)減価償却費 100,000 (貸)減価償却累計額 100,000
例題: 取得原価400,000円、残存価額は取得原価の10%、耐用年数8年 残存価額 = 400,000円 × 10% = 40,000円
年間減価償却費 = (400,000円 − 40,000円) ÷ 8年 = 360,000円 ÷ 8年 = 45,000円
方法仕訳の考え方帳簿上の表示
直接法(借)減価償却費 ×× (貸)備品 ××固定資産の帳簿価額を直接減額する
間接法(借)減価償却費 ×× (貸)減価償却累計額 ××取得原価はそのまま残し、減価償却累計額を控除して表示する(3級で主に出題される方法)
つまずきやすいポイント 残存価額がある場合(「取得原価の10%」など)は、取得原価からその金額を差し引いてから耐用年数で割ることを忘れない。また間接法では減価償却累計額を貸方に計上し、備品などの取得原価そのものは減らさない(直接法のように取得原価を直接減らすわけではない)点に注意する。
練習問題 0 / 2問 正解

問1　決算にあたり、備品(取得原価500,000円、残存価額0円、耐用年数5年)について、定額法・間接法で減価償却を行う。

(500,000 − 0) ÷ 5年 = 100,000円。間接法では備品を直接減らさず、減価償却累計額を貸方に記入する。

問2　取得原価800,000円、残存価額は取得原価の10%、耐用年数9年の建物を定額法で償却する。1年分の減価償却費はどれか。

残存価額は 800,000 × 10% = 80,000円。(800,000 − 80,000) ÷ 9年 = 80,000円。残存価額を引き忘れると88,889円になる。

3貸倒引当金(差額補充法)

売掛金や受取手形などの金銭債権は、将来相手先が支払不能となり回収できなくなる(貸し倒れる)おそれがある。そこで決算にあたり、将来の貸し倒れに備えてあらかじめ見積もり計上しておく金額が貸倒引当金である。3級では、期末債権残高に一定の設定率を掛けて設定額を求める方法が中心となる。

貸倒引当金の設定にあたり、決算整理前にすでに貸倒引当金の残高がある場合、設定額と既存残高との差額だけを追加で繰り入れる方法を差額補充法と呼ぶ。3級で最も頻出する処理方法である。

差額補充法による貸倒引当金繰入額 (期末債権残高 × 貸倒設定率) − 貸倒引当金の決算整理前残高 = 貸倒引当金繰入額
例題: 売掛金残高200,000円、設定率2%、既存残高1,000円 設定額 = 200,000円 × 2% = 4,000円
貸倒引当金繰入額 = 4,000円 − 1,000円 = 3,000円
仕訳: (借)貸倒引当金繰入 3,000 (貸)貸倒引当金 3,000
項目内容
貸倒引当金将来の貸し倒れに備えて見積もり計上する評価性の勘定(貸方に残高を持つ)
貸倒引当金繰入貸倒引当金を積み増す際に計上する費用の勘定
差額補充法設定額と決算整理前残高との差額のみを繰入額として計上する方法
つまずきやすいポイント 差額補充法では、設定額(期末債権残高×設定率)をそのまま繰入額としてはならない。必ず決算整理前の貸倒引当金残高を確認し、その差額のみを貸倒引当金繰入として計上する。
練習問題 0 / 2問 正解

問1　決算にあたり、売掛金の期末残高400,000円に対して2%の貸倒引当金を差額補充法で設定する。貸倒引当金の残高は3,000円ある。

設定額は 400,000 × 2% = 8,000円。すでに3,000円あるので、差額の5,000円だけを繰り入れる。

問2　売掛金の期末残高250,000円に対して3%の貸倒引当金を差額補充法で設定する。貸倒引当金の残高が2,000円あるとき、貸倒引当金繰入の金額はどれか。

設定額は 250,000 × 3% = 7,500円。差額補充法なので 7,500 − 2,000 = 5,500円を繰り入れる。7,500円をそのまま繰り入れるのは誤り。

4売上原価の算定(三分法)

商品売買を仕入・売上・繰越商品の3つの勘定で記帳する方法を三分法と呼ぶ。三分法では、期中の仕入時に仕入勘定へ全額を記帳するため、決算にあたって「実際に販売した商品の原価」である売上原価を別途算定し直す必要がある。

売上原価の算定 期首商品棚卸高 + 当期商品仕入高 − 期末商品棚卸高 = 売上原価
例題: 期首商品棚卸高50,000円、当期商品仕入高300,000円、期末商品棚卸高40,000円 売上原価 = 50,000円 + 300,000円 − 40,000円 = 310,000円
決算整理仕訳①(期首商品棚卸高を仕入に加算): (借)仕入 50,000 (貸)繰越商品 50,000
決算整理仕訳②(期末商品棚卸高を仕入から差し引く): (借)繰越商品 40,000 (貸)仕入 40,000

この一連の決算整理は「仕入」と「繰越商品」の2つの勘定科目のみを用いて行う点が特徴である。①で前期繰越の商品(期首商品棚卸高)をいったん仕入勘定に戻し、②で当期末に売れ残った商品(期末商品棚卸高)を仕入勘定から繰越商品勘定へ振り替えることで、仕入勘定の残高が最終的に売上原価を示すことになる。

つまずきやすいポイント 仕入勘定への振替は「期首棚卸高を仕入に加算(繰越商品→仕入)」「期末棚卸高を仕入から控除(仕入→繰越商品)」の2本の仕訳から成る。どちらも勘定科目は仕入と繰越商品のみであり、売上勘定は登場しない点に注意する(売上と混同しない)。
練習問題 0 / 3問 正解

問1　期首商品棚卸高60,000円、当期商品仕入高500,000円、期末商品棚卸高80,000円のとき、売上原価はどれか。

売上原価 = 期首商品棚卸高 + 当期商品仕入高 − 期末商品棚卸高 = 60,000 + 500,000 − 80,000 = 480,000円。

問2　決算にあたり、期首商品棚卸高60,000円を仕入勘定に振り替える。

前期から繰り越した商品は当期に売られたものとして、繰越商品から仕入に振り替える(仕入に加える)。

問3　決算にあたり、期末商品棚卸高80,000円を仕入勘定から繰越商品勘定に振り替える。

売れ残った商品は当期の原価から差し引き、繰越商品(資産)として次期に繰り越す。

5現金過不足の整理

現金の実際有高と帳簿残高が一致しない場合、いったん現金過不足という仮勘定で差額を処理する。決算日までに原因が判明した分は本来の勘定に振り替え、それでも原因が判明しない残額は、決算整理で最終的に雑損(費用)または雑益(収益)に振り替える。

例題: 現金過不足(借方)3,000円の原因が決算日まで判明しなかった場合 仕訳: (借)雑損 3,000 (貸)現金過不足 3,000
逆に現金が実際有高の方が多く超過していた場合は、雑益(収益)として計上する。
つまずきやすいポイント 現金過不足勘定はあくまで一時的な仮勘定であり、貸借対照表・損益計算書には残せない。決算日を迎えても原因が不明な残高は、不足なら雑損(費用)、超過なら雑益(収益)に必ず振り替えて残高をゼロにする。
練習問題 0 / 2問 正解

問1　決算にあたり、現金過不足勘定の借方残高4,000円のうち3,000円は通信費の記入もれと判明した。残額は原因不明である。

借方残高(現金の不足)を取り消すため現金過不足を貸方に記入し、原因がわかった3,000円は通信費、わからない1,000円は雑損(費用)とする。

問2　決算にあたり、現金過不足勘定の貸方残高2,500円の原因が最後まで判明しなかった。

貸方残高(現金が多かった分)で原因がわからないものは、雑益(収益)に振り替える。

6その他の決算整理(貯蔵品・銀行勘定調整表・有価証券・法人税等)

ここでは、出題数は少ないものの決算整理として押さえておくべき論点を横断的にまとめる。

通信費として処理した郵便切手や、租税公課として処理した収入印紙のうち、期末に未使用のまま残っているものは、貯蔵品(資産)に振り替えて次期に繰り越す。翌期首には再振替仕訳を行い、もとの費用勘定に振り戻す。

例題: 未使用の郵便切手2,000円を貯蔵品に振り替える 決算整理仕訳: (借)貯蔵品 2,000 (貸)通信費 2,000
翌期首の再振替仕訳: (借)通信費 2,000 (貸)貯蔵品 2,000
例題: 未使用の収入印紙5,000円の翌期首の再振替仕訳 決算整理仕訳: (借)貯蔵品 5,000 (貸)租税公課 5,000
翌期首の再振替仕訳: (借)租税公課 5,000 (貸)貯蔵品 5,000

企業の当座預金勘定の残高と、銀行が発行する残高証明書の残高が一致しないことがある。この不一致の原因(未取立小切手・未渡小切手・時間外預入など)を明らかにするために作成する表を銀行勘定調整表と呼ぶ。

売買目的で保有する有価証券は、決算日に時価で評価替えする。帳簿価額よりも時価が値上がりしていれば有価証券評価益(収益)、値下がりしていれば有価証券評価損(費用)を計上する。

例題: 売買目的有価証券(帳簿価額80,000円)の決算日の時価が95,000円の場合 評価差額 = 95,000円 − 80,000円 = 15,000円
仕訳: (借)売買目的有価証券 15,000 (貸)有価証券評価益 15,000

法人税・住民税及び事業税(法人税等)は、期中に中間申告を行い一部を納付し、決算で年税額が確定した後、中間納付額を差し引いた残額を未払法人税等として計上する。

例題: 中間申告150,000円を現金納付、決算で年税額320,000円が確定 中間申告時の仕訳: (借)仮払法人税等 150,000 (貸)現金 150,000
決算時の仕訳: (借)法人税等 320,000 (貸)仮払法人税等 150,000 (貸)未払法人税等 170,000
未払法人税等 = 320,000円 − 150,000円 = 170,000円
論点要点
貯蔵品未使用の切手・印紙などを費用から資産(貯蔵品)へ振り替え、翌期首に再振替仕訳で戻す
銀行勘定調整表当座預金勘定の残高と銀行残高証明書の残高の不一致原因を明らかにする表
有価証券の評価替え売買目的有価証券を時価評価し、差額を評価益(収益)または評価損(費用)として計上する
法人税等中間納付額は仮払法人税等(資産)、決算確定額との差額は未払法人税等(負債)として計上する
つまずきやすいポイント 有価証券は時価が帳簿価額より「上がれば評価益(収益)」「下がれば評価損(費用)」であり、方向を逆にしない。また貯蔵品は決算整理仕訳と翌期首の再振替仕訳とで、借方・貸方の勘定科目がちょうど逆になる点を押さえておく。
練習問題 0 / 3問 正解

問1　決算にあたり、通信費として処理していた郵便切手のうち3,000円分が未使用で残っていた。

未使用の切手は費用から貯蔵品(資産)に振り替えて次期に繰り越す。翌期首には逆の仕訳で通信費に戻す。

問2　決算にあたり、売買目的有価証券(帳簿価額120,000円)の時価が105,000円に下がっていたので、評価替えをする。

時価が帳簿価額より15,000円下がったので、有価証券を15,000円減らし、有価証券評価損(費用)を計上する。

問3　決算にあたり、法人税等の年税額が280,000円と確定した。中間申告で120,000円を納付済みである。

年税額280,000円を法人税等とし、中間納付の仮払法人税等120,000円を取り崩す。残り160,000円はこれから納める未払法人税等(負債)とする。

7当期純利益の算定

これまでの決算整理を経て、当期に属する収益・費用がすべて確定する。この収益総額と費用総額の差額として算定されるのが当期純利益であり、一会計期間の経営成績を示す損益計算書上の最終的な数値である。

当期純利益の算定 収益総額 − 費用総額 = 当期純利益
例題: 収益総額と費用総額から当期純利益を求める 売上高500,000円、受取利息6,000円のとき
収益総額 = 500,000円 + 6,000円 = 506,000円
売上原価310,000円、給料80,000円、減価償却費45,000円、その他費用20,000円のとき
費用総額 = 310,000円 + 80,000円 + 45,000円 + 20,000円 = 455,000円
当期純利益 = 506,000円 − 455,000円 = 51,000円

決算整理後は、収益・費用の各勘定を損益勘定に振り替え(決算振替仕訳)、その差額として計算された当期純利益を繰越利益剰余金(資本)に振り替える。これにより、当期純利益は貸借対照表上の純資産(資本)の増加としても反映される。

つまずきやすいポイント 当期純利益は「収益総額−費用総額」であり、「資産総額−負債総額」(これは資本の額を表す)とは別の計算である。両者は最終的に一致する関係にあるが、算定の式そのものを混同しないこと。
練習問題 0 / 2問 正解

問1　決算整理後の金額が、売上800,000円、受取手数料20,000円、売上原価520,000円、給料150,000円、減価償却費40,000円であった。当期純利益はどれか。

収益総額 = 800,000 + 20,000 = 820,000円、費用総額 = 520,000 + 150,000 + 40,000 = 710,000円。当期純利益 = 820,000 − 710,000 = 110,000円。

問2　当期純利益を求める式として正しいものはどれか。

当期純利益は収益総額から費用総額を引いて求める。資産総額 − 負債総額は資本(純資産)の額、売上高 − 売上原価は売上総利益である。
