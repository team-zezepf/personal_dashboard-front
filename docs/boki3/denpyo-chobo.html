伝票・帳簿のまとめ

取引をいったん伝票に記入してから帳簿へ転記する仕組みと、仕訳帳・総勘定元帳(主要簿)や現金出納帳・商品有高帳などの補助簿の役割を解説します。読み終えたら下部から問題を解いて定着させましょう。

1伝票会計と三伝票制(入金伝票・出金伝票・振替伝票)

日々の取引は、いきなり仕訳帳に記入するのではなく、まず1件ごとに伝票と呼ばれる紙(またはその電子データ)に記入し、それをもとに帳簿へ転記していく方法がとられることが多い。取引を現金の収入・支出・それ以外の3種類に区分し、それぞれ専用の伝票(入金伝票・出金伝票・振替伝票)に記入する方式を三伝票制という。

入金伝票: 現金の収入(入金)を伴う取引だけを記入する
出金伝票: 現金の支出(出金)を伴う取引だけを記入する
振替伝票: 現金の収支を伴わない取引(掛け取引・手形取引など)を記入する

例えば、商品を売り上げてその場で現金を受け取れば入金伝票、文房具代を現金で支払えば出金伝票を用いる。一方、商品を掛けで仕入れた・売り上げたなど、現金の受け渡しがその場で発生しない取引は振替伝票に記入する。

代金の一部を現金で受け払いし、残りを掛けなどにする取引を一部振替取引という。現金の部分とそれ以外の部分があるため、入金（出金）伝票と振替伝票の2枚に分けて記入する。分け方には次の2つの方法があり、入金（出金）伝票の勘定科目を見ればどちらの方法かが分かる。

方法入金伝票振替伝票
取引を分解する方法（現金）売上 40,000（借）売掛金 110,000（貸）売上 110,000
全額を掛け取引とみなす方法（現金）売掛金 40,000（借）売掛金 150,000（貸）売上 150,000
例題: 一部振替取引（商品 150,000円を売り上げ、40,000円は現金で受け取り、残りは掛け） 取引を分解する方法: 現金で受け取った 40,000円を「現金/売上」として入金伝票に、掛けの 110,000円を「売掛金/売上」として振替伝票に記入する。
全額を掛け取引とみなす方法: いったん 150,000円全額を「売掛金/売上」として振替伝票に記入し、すぐに 40,000円を回収したとみなして「現金/売掛金」を入金伝票に記入する。
どちらの方法でも、2枚の伝票を合わせると元の仕訳 （借）現金 40,000・売掛金 110,000（貸）売上 150,000 と同じになる。
つまずきやすいポイント どの伝票を使うかは「現金が動いたかどうか」だけで判断する。掛け取引は将来的に現金の受け渡しにつながるが、その取引が発生した時点では現金が動いていないため振替伝票を使う。「お金に関係する取引だから入金伝票・出金伝票」と早合点しないこと。
練習問題 0 / 3問 正解

問1　三伝票制で、商品を掛けで売り上げたときに記入する伝票はどれか。

掛けの売上は、その時点では現金が動いていないので振替伝票に記入する。

問2　三伝票制で、文房具代を現金で支払ったときに記入する伝票はどれか。

現金の支出をともなう取引は出金伝票に記入する。

問3　商品 80,000円を仕入れ、代金のうち 30,000円は現金で支払い、残りは掛けとした。出金伝票に「買掛金 30,000円」と記入したとき、振替伝票の記入として正しいものはどれか。

出金伝票の科目が「買掛金」なので、全額を掛け取引とみなす方法である。振替伝票には全額の「（借）仕入 80,000（貸）買掛金 80,000」を記入し、出金伝票で買掛金 30,000円を支払ったとみなす。アは取引を分解する方法（出金伝票が「仕入 30,000」のとき）の振替伝票。

2仕訳日計表(伝票の集計から総勘定元帳への転記)

伝票制を採用している場合、1枚1枚の伝票を都度総勘定元帳へ転記するのではなく、1日分の伝票をいったん勘定科目ごとに集計してから、その合計額をまとめて転記する方法がよく用いられる。この集計表を仕訳日計表という。

伝票の枚数が多い企業では、伝票1枚ごとに個別転記するより、1日分をまとめて合計転記するほうが手間が少なく、転記漏れも防ぎやすいという利点がある。

練習問題 0 / 2問 正解

問1　ある日の伝票は、入金伝票が 売上30,000円・売掛金20,000円・受取利息1,000円、出金伝票が 仕入15,000円・旅費交通費4,000円 であった。仕訳日計表の現金勘定の借方に記入する金額はどれか。

入金伝票はすべて現金が増える取引なので、その合計 30,000 + 20,000 + 1,000 = 51,000円が現金の借方になる。出金伝票の合計19,000円は現金の貸方になる。

問2　仕訳日計表の説明として正しいものはどれか。

仕訳日計表で1日分をまとめてから合計転記すると、伝票1枚ずつ転記するより手間が少なく、転記もれも防ぎやすい。

3主要簿(仕訳帳・総勘定元帳)

帳簿のうち、すべての企業が必ず作成しなければならない基本の帳簿を主要簿といい、仕訳帳と総勘定元帳の2つを指す。仕訳帳は日々の取引を発生順(取引が起きた順)に仕訳の形で記録する帳簿であり、総勘定元帳は仕訳帳に記入された内容をすべての勘定科目ごとに転記し、各勘定の増減と残高を管理するための帳簿である。

帳簿記録の単位目的
仕訳帳取引の発生順(時系列)日々の取引を仕訳の形でもれなく記録する
総勘定元帳勘定科目ごと勘定科目ごとの増減と残高を把握する

仕訳帳に記入された仕訳は、その後、該当する勘定科目の総勘定元帳へ転記される。「取引 → 仕訳帳 → 総勘定元帳」という流れによって、日々の取引が最終的に各勘定科目の残高として集約される。

練習問題 0 / 2問 正解

問1　主要簿の組合せとして正しいものはどれか。

すべての企業が必ず作る主要簿は仕訳帳と総勘定元帳。現金出納帳・商品有高帳・売上帳・仕入帳は補助簿である。

問2　日々の取引を発生した順に、仕訳の形で記録する帳簿はどれか。

仕訳帳は取引の発生順に仕訳を記録する。総勘定元帳は仕訳帳の内容を勘定科目ごとに転記した帳簿である。

4補助簿(現金出納帳・売掛金元帳・仕入帳・商品有高帳など)

主要簿(仕訳帳・総勘定元帳)は全体像を把握するための帳簿だが、特定の勘定科目や取引についてより詳しい内訳を知りたい場合に用いるのが補助簿である。補助簿は、企業の取引内容に応じて必要なものだけを任意で作成する点が主要簿と異なる。

補助簿記録する内容
現金出納帳現金の増減(収入・支出)と残高を記録する
当座預金出納帳当座預金の預け入れ・引き出しと残高を記録する
売掛金元帳(得意先元帳)得意先ごとに売掛金の発生・回収・残高を記録する
買掛金元帳(仕入先元帳)仕入先ごとに買掛金の発生・支払・残高を記録する
仕入帳商品の仕入取引の明細(仕入先・品名・数量・金額など)を発生順に記録する
売上帳商品の売上取引の明細を発生順に記録する
商品有高帳商品の種類ごとに受け入れ・払い出し・残高を数量・単価・金額で記録する
固定資産台帳固定資産ごとの取得日・取得原価・減価償却の状況などを記録する
例題: どの補助簿に記録するか 得意先A社に商品を掛けで売り上げた場合、A社に対する売掛金の残高がいくらになったかを知りたければ売掛金元帳を見る。一方、どの商品が何個手元に残っているかを知りたければ商品有高帳を見る。
つまずきやすいポイント 仕訳帳・総勘定元帳(主要簿)はすべての企業が必ず作成する帳簿であるのに対し、補助簿(現金出納帳・売掛金元帳・商品有高帳など)はあくまで取引の種類に応じて必要なものだけを作成する補助的な記録である。「主要簿=全社共通で必須」「補助簿=必要に応じて選んで作成」という位置づけの違いを混同しないこと。
練習問題 0 / 2問 正解

問1　得意先ごとに売掛金の発生・回収・残高を記録する補助簿はどれか。

売掛金元帳(得意先元帳)は得意先ごとの売掛金の明細を記録する。売上帳は売上取引の明細を発生順に記録する。

問2　商品の種類ごとに、受け入れ・払い出し・残高を数量・単価・金額で記録する補助簿はどれか。

商品有高帳は商品ごとの在庫の動きを数量・単価・金額で記録する。仕入帳は仕入取引の明細を発生順に記録する。

5商品有高帳の記入(先入先出法・移動平均法)

商品有高帳は、商品の種類ごとに「受入」「払出」「残高」を、数量・単価・金額で記録する補助簿である。金額はすべて原価（仕入単価）で記入し、売価は書かない。同じ商品でも仕入れた時期によって単価が違うため、払い出した商品の単価をどう決めるかで、先入先出法と移動平均法の2つの方法がある。

練習問題 0 / 2問 正解

問1　前月繰越 20個（@50円）、3日に 30個（@60円）を仕入れ、9日に 35個を売り上げた。先入先出法で記入したとき、9日の払出金額はいくらか。

先に受け入れた前月繰越の20個から払い出し、足りない15個を3日仕入分から払い出す。20個 × 50 + 15個 × 60 = 1,000 + 900 = 1,900円。エの1,960円は移動平均法（@56円）で計算した場合。

問2　前月繰越 10個（@200円）、5日に 30個（@240円）を仕入れた。移動平均法で記入したとき、5日の残高欄の単価はいくらか。

(10個 × 200 + 30個 × 240) ÷ 40個 = (2,000 + 7,200) ÷ 40 = 230円。単価を単純に平均した220円（アの (200 + 240) ÷ 2）は誤り。数量で重みをつけて平均する。

6勘定の記入と締め切り

総勘定元帳の勘定口座は、左側を借方、右側を貸方とし、T字形で表すことが多い。仕訳の借方の金額はその勘定の借方に、貸方の金額は貸方に記入し、摘要には相手の勘定科目を書く（相手が2つ以上なら「諸口」）。第2問では、勘定の空欄を埋めたり、決算で勘定を締め切ったりする問題が出る。

勘定の種類決算での締め切り方翌期首
資産・負債・純資産残高を、残高と反対側に「次期繰越」と書いて貸借を一致させ、締め切る次期繰越と反対側に「前期繰越」と書く
収益・費用残高を「損益」勘定へ振り替えて、残高をゼロにして締め切る（繰り越さない。経過勘定の再振替のみ）
例題: 売掛金勘定を締め切る 前期繰越 300,000円、当期の掛売上 1,200,000円、売掛金の回収（現金）1,050,000円、前期発生の売掛金の貸倒れ 20,000円（貸倒引当金を取り崩した）。

借方合計 1,500,000円 − 貸方の記入 1,070,000円 = 430,000円 が残高で、貸方に「次期繰越 430,000」と書いて貸借を一致させる。翌期首には借方に「前期繰越 430,000」と書く。

例題: 保険料勘定（再振替あり）を締め切る 会計期間は4月1日〜3月31日。前期末に前払保険料 8,000円（4月〜7月の4か月分）を計上していた。当期の8月1日に1年分 30,000円を支払い、決算で前払分 10,000円（翌期の4か月分）を計上した。

つまずきやすいポイント 「次期繰越」は残高と同じ側ではなく、反対側に書く（売掛金のように借方残高の勘定なら貸方に書く）。損益勘定で計算した当期純利益は「（借）損益（貸）繰越利益剰余金」で純資産へ振り替える。

問1　買掛金勘定の記録が、前期繰越 180,000円、当期の掛仕入 640,000円、買掛金の支払い 590,000円、仕入戻し 10,000円 であった。次期繰越はいくらか。

買掛金は貸方に前期繰越と掛仕入、借方に支払いと仕入戻しを記入する。180,000 + 640,000 − 590,000 − 10,000 = 220,000円 を借方に「次期繰越」と書いて締め切る。

問2　決算振替後の損益勘定で、収益の合計が 820,000円、費用の合計が 760,000円 であった。損益勘定を締め切る仕訳として正しいものはどれか。

収益 820,000円 − 費用 760,000円 = 当期純利益 60,000円。損益勘定の貸方残高を繰越利益剰余金（純資産）へ振り替える。純損失のときは貸借が逆になる。

7補助簿の選び方・固定資産台帳

第2問では「取引を記入する補助簿をすべて選ぶ」問題がよく出る。まず取引を仕訳にし、出てきた勘定科目ごとに補助簿を当てはめると、漏れなく選べる。

仕訳に出てくる勘定科目記入する補助簿
現金現金出納帳
当座預金当座預金出納帳
売掛金 ／ 買掛金売掛金元帳（得意先元帳）／ 買掛金元帳（仕入先元帳）
受取手形 ／ 支払手形受取手形記入帳 ／ 支払手形記入帳
売上売上帳 と 商品有高帳
仕入仕入帳 と 商品有高帳
備品・建物・車両運搬具など固定資産台帳
例題: 補助簿を選ぶ 商品 200,000円を売り上げ、代金のうち 50,000円は得意先が振り出した小切手で受け取り、残りは同店振出の約束手形で受け取った。
仕訳: （借）現金 50,000・受取手形 150,000（貸）売上 200,000
→ 現金で現金出納帳、受取手形で受取手形記入帳、売上で売上帳と商品有高帳（商品が出ていく）
つまずきやすいポイント 他人が振り出した小切手を受け取ったら「現金」（現金出納帳）、自分が振り出した小切手で支払ったら「当座預金」（当座預金出納帳）。商品の返品（売上戻り・仕入戻し）も商品が動くので商品有高帳に記入する。備品などの購入は商品の売買ではないので、仕入帳・商品有高帳には記入しない。

固定資産台帳は、固定資産ごとに取得日・取得原価・耐用年数・減価償却累計額などを記録する補助簿である。台帳の金額から、当期の減価償却費や期末の減価償却累計額を求める問題が出る。期中に取得したものは月割で計算する。

名称取得日取得原価耐用年数期首の減価償却累計額当期の減価償却費
備品AX0年4月1日600,0005年120,000120,000
備品BX1年10月1日480,0004年060,000

会計期間が X1年4月1日〜X2年3月31日、定額法（残存価額ゼロ）の場合、備品Aは 600,000 ÷ 5年 = 120,000円、備品Bは期中取得なので 480,000 ÷ 4年 × 6/12 = 60,000円。期末の減価償却累計額は (120,000 + 120,000) + 60,000 = 300,000円 になる。

問1　商品 80,000円を仕入れ、代金は小切手を振り出して支払った。この取引を記入する補助簿の組み合わせとして正しいものはどれか（主要簿は除く）。

仕訳は「（借）仕入 80,000（貸）当座預金 80,000」。自分で振り出した小切手なので当座預金出納帳、仕入で仕入帳と商品有高帳に記入する。掛けではないので買掛金元帳には記入しない。

問2　会計期間は X1年4月1日〜X2年3月31日である。固定資産台帳に「車両運搬具、取得日 X1年7月1日、取得原価 1,200,000円、耐用年数5年」とある。定額法（残存価額ゼロ）による当期の減価償却費はいくらか。

期中（7月1日）に取得したので、7月〜3月の9か月分を月割で計上する。1,200,000 ÷ 5年 × 9/12 = 180,000円。アの240,000円は1年分。
