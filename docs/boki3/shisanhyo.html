試算表のまとめ

試算表の意義と貸借平均の原理、合計試算表・残高試算表・合計残高試算表の違い、精算表の構造、そして試算表で発見できる誤りとできない誤りまでを図解しています。読み終えたら下部から問題を解いて定着させましょう。

1試算表の意義と貸借平均の原理

試算表とは、総勘定元帳に記録された各勘定科目の金額を一覧にまとめ、仕訳から元帳への転記が正しく行われているかを検証するために作成する表である。決算の前などに作成し、転記もれや金額の誤りがないかを確認する役割を持つ。

複式簿記では、1つの取引を必ず借方・貸方の両面に同じ金額で記入する。そのため、どれだけ多くの取引を記録しても、すべての勘定の借方合計金額と貸方合計金額は必ず一致する。この性質を貸借平均の原理といい、試算表によって転記の正確性を検証できる根拠となっている。

借方残高勘定科目貸方残高
150,000現金
80,000売掛金
買掛金40,000
資本金100,000
売上200,000
110,000仕入

例題: 貸借が一致することを確かめる 上の残高試算表について、借方残高の合計は 150,000円+80,000円+110,000円=340,000円、貸方残高の合計は 40,000円+100,000円+200,000円=340,000円となり、両者は一致する。これは、どの取引も借方・貸方の両方に同じ金額を記入するため、元帳を勘定科目ごとに集計しなおしても貸借の合計は崩れない、という貸借平均の原理によるものである。
練習問題 0 / 2問 正解

問1　試算表を作成する主な目的はどれか。

試算表は元帳の各勘定の金額を一覧にし、借方と貸方の合計が一致するかで転記の正しさを確かめる。

問2　残高試算表の借方に 現金200,000円・売掛金100,000円・仕入150,000円、貸方に 買掛金80,000円・資本金(?)・売上250,000円 が記入されている。資本金の金額はどれか。

借方合計は 200,000 + 100,000 + 150,000 = 450,000円。貸方合計も450,000円になるので、資本金 = 450,000 − 80,000 − 250,000 = 120,000円。

2試算表の3種類(合計試算表・残高試算表・合計残高試算表)

試算表には集計の仕方によって3つの種類がある。それぞれ集計する金額が異なるだけで、もとになる元帳のデータは同じである。

種類集計する金額特徴
合計試算表各勘定の借方合計額・貸方合計額をそのまま集計借方合計は仕訳帳の借方合計と、貸方合計は仕訳帳の貸方合計と、それぞれ一致する
残高試算表各勘定の借方・貸方の差額(残高)のみを集計各勘定の最終的な残高だけが分かり、財務諸表の作成につながりやすい
合計残高試算表合計試算表と残高試算表を1つの表にまとめたもの借方残高・借方合計・貸方合計・貸方残高を1行で確認できる

例題: 合計試算表の借方合計は仕訳帳の借方合計と一致する 合計試算表は、仕訳帳に記入された取引をそのまま勘定科目ごとに集計しなおしたものである。そのため合計試算表の借方合計金額は仕訳帳の借方合計金額と、貸方合計金額は仕訳帳の貸方合計金額と、それぞれ必ず一致する。
練習問題 0 / 2問 正解

問1　各勘定の借方合計額と貸方合計額をそのまま集計する試算表はどれか。

合計試算表は借方・貸方の合計額を、残高試算表は差額(残高)だけを集計する。合計残高試算表はその両方を1つの表にしたもの。

問2　現金勘定の借方合計が500,000円、貸方合計が320,000円である。残高試算表にはどのように記入するか。

残高は 500,000 − 320,000 = 180,000円。借方のほうが多いので借方残高として記入する。

3精算表

精算表は、試算表に決算整理(修正記入)を加えて損益計算書・貸借対照表を作成するまでの過程を1つの表にまとめたものである。決算手続きの全体像を一覧できるため、決算の下書きとしてよく利用される。

精算表は「試算表欄」「修正記入欄」「損益計算書欄」「貸借対照表欄」の4つの欄からなり、それぞれがさらに借方・貸方に分かれる。試算表欄の金額に修正記入欄の金額を加減し、収益・費用の勘定は損益計算書欄へ、資産・負債・資本の勘定は貸借対照表欄へ書き移していく。

例題: 当期純利益はどこに記入されるか 損益計算書欄で貸方(収益)の合計が借方(費用)の合計より大きいとき、その差額は当期純利益を意味する。損益計算書欄では差額を借方に記入して貸借を一致させ、貸借対照表欄では同じ金額を貸方に記入する。これは、利益が生じた分だけ資本(純資産)が増加したことを表すためである。
つまずきやすいポイント 損益計算書欄と貸借対照表欄とで、当期純利益を記入する側(借方・貸方)が逆になる点に注意する。損益計算書欄では借方に、貸借対照表欄では貸方に記入する。逆に当期純損失が生じた場合は、この記入する側がすべて反対になる。
練習問題 0 / 2問 正解

問1　精算表で当期純利益が生じたとき、その金額を記入する欄の組合せとして正しいものはどれか。

損益計算書欄では差額を借方に書いて貸借を合わせ、貸借対照表欄では同じ金額を貸方に書く(利益の分だけ純資産が増える)。

問2　精算表で、売掛金の金額を書き移す欄はどれか。

売掛金は資産なので貸借対照表欄に移し、資産は借方に記入する。収益・費用の勘定は損益計算書欄に移す。

4試算表による検証とその限界

試算表を作成したときに借方合計と貸方合計が一致しない場合は、仕訳や転記のどこかに、借方・貸方のいずれか一方にだけ影響する誤り(記入もれや金額の書き間違いなど)が生じていると考えられる。試算表はこうした誤りを発見するために作成される。

ただし、借方合計と貸方合計が一致したからといって、記帳にまったく誤りがないとは限らない。借方・貸方の両方に同じ影響を与える誤りは、貸借の金額そのものが崩れないため試算表では発見できない。これを試算表の限界という。

誤りの例試算表で発見できるか
取引の借方・貸方のどちらか一方だけを転記した(片側の記入もれ)発見できる(貸借が一致しなくなる)
借方と貸方とで異なる金額を記入した(金額の誤記)発見できる(貸借が一致しなくなる)
ある取引を借方・貸方ともに記入し忘れた(取引全体の記帳もれ)発見できない(貸借は一致したままになる)
正しい金額・正しい貸借で、本来と異なる勘定科目に転記した発見できない(貸借は一致したままになる)
ある取引の借方・貸方を取り違えて記入した(貸借の逆記入)発見できない(貸借の合計自体は変わらない)
つまずきやすいポイント 試算表の貸借合計が一致していても、転記や仕訳に誤りがないとは限らない。取引全体の記帳もれ、勘定科目の書き間違い、貸借の逆記入などは、借方・貸方の金額そのものは変わらないため、試算表上では貸借が一致してしまい発見できない。「貸借が一致=誤りなし」と早合点しないこと。
練習問題 0 / 2問 正解

問1　試算表を作成することで発見できる誤りはどれか。

片側だけの転記もれは貸借の合計が一致しなくなるので発見できる。それ以外は借方・貸方に同じ影響が出るため、合計は一致したままで発見できない。

問2　商品50,000円を現金で仕入れた取引を、誤って (借方)現金 50,000 / (貸方)仕入 50,000 と記帳した。試算表の借方合計と貸方合計はどうなるか。

貸借を逆に記入しても、借方と貸方には同じ50,000円が記入されるので合計は一致する。試算表では発見できない誤りである。
