仕訳のまとめ

商品売買・債権債務・手形・固定資産・現金預金・資本・給与・貸倒れ・有価証券など、仕訳で問われる主要な取引について、借方・貸方のどちらにどの勘定科目を記入するかを豊富な仕訳例とともに解説しています。読み終えたら下部から問題を解いて定着させましょう。

1仕訳の基本ルールと商品売買の仕訳

複式簿記では、1つの取引を「借方(左側)」と「貸方(右側)」の両方に記入し、借方合計と貸方合計は必ず一致する。勘定科目は資産・負債・資本(純資産)・収益・費用の5要素のいずれかに分類され、それぞれ増加(発生)したときに記入する側が決まっている。

分類増加(発生)時に記入する側代表的な勘定科目
資産借方現金・当座預金・売掛金・受取手形・前払金・仮払金・備品・貸付金・有価証券・受取商品券・クレジット売掛金・電子記録債権
負債貸方買掛金・支払手形・借入金・前受金・仮受金・預り金・電子記録債務
資本(純資産)貸方資本金
収益貸方売上・受取利息・受取手数料・償却債権取立益・雑益
費用借方仕入・旅費交通費・広告宣伝費・支払利息・保険料・租税公課・見本品費・貸倒損失・手形売却損・給料・法定福利費

商品売買を仕入・売上の総額でそのまま処理する方法を三分法といい、日商簿記3級ではこの方法が基本となる。仕入れたときは仕入(費用)を借方に、代金の支払い方法(現金・掛けなど)に応じた勘定科目を貸方に記入する。売り上げたときは代金の受取り方法に応じた勘定科目を借方に、売上(収益)を貸方に記入する。

例題: 現金による仕入 取引: 商品50,000円を現金で仕入れた。
仕訳: (借方)仕入 50,000円 / (貸方)現金 50,000円
例題: 掛けによる仕入 取引: 商品80,000円を掛けで仕入れた。
仕訳: (借方)仕入 80,000円 / (貸方)買掛金 80,000円
例題: 現金による売上 取引: 商品120,000円を売り上げ、代金を現金で受け取った。
仕訳: (借方)現金 120,000円 / (貸方)売上 120,000円
例題: 掛けによる売上 取引: 商品90,000円を掛けで売り上げた。
仕訳: (借方)売掛金 90,000円 / (貸方)売上 90,000円
例題: 仕入戻し(返品) 取引: 仕入れた商品の一部に品違いがあったため、10,000円分を仕入先に返品した。
仕訳: (借方)買掛金 10,000円 / (貸方)仕入 10,000円(仕入の取り消しなので、仕入を貸方に記入する)
例題: 売上戻り(返品) 取引: 得意先に掛けで売り上げていた商品のうち15,000円分が返品された。
仕訳: (借方)売上 15,000円 / (貸方)売掛金 15,000円(売上の取り消しなので、売上を借方に記入する)
例題: クレジットカード払いによる売上 取引: クレジットカード払いの条件で商品50,000円を売り上げた(信販会社への手数料は考慮しない)。
仕訳: (借方)クレジット売掛金 50,000円 / (貸方)売上 50,000円(信販会社に対する債権であり、通常の売掛金とは区別する)
つまずきやすいポイント 仕入戻し(仕入の取り消し)は仕入を貸方に、売上戻り(売上の取り消し)は売上を借方に記入する。通常の仕入・売上と記入する側が逆になる点を混同しないこと。また、クレジットカード払いの売上は「クレジット売掛金」という専用の勘定科目を用い、通常の「売掛金」とは区別する。
練習問題 0 / 3問 正解

問1　商品60,000円を仕入れ、代金は掛けとした。

仕入(費用)の発生を借方に、後で代金を支払う義務である買掛金(負債)の増加を貸方に記入する。

問2　商品100,000円を売り上げ、代金のうち30,000円は現金で受け取り、残額は掛けとした。

受け取った現金30,000円と、後で受け取る売掛金70,000円(100,000円−30,000円)を借方に、売上100,000円を貸方に記入する。借方の合計と貸方の合計は一致する。

問3　三分法で、商品を仕入れたときに借方に記入する勘定科目はどれか。

三分法では仕入れたときは「仕入」(費用)、売ったときは「売上」(収益)で処理し、期末に「繰越商品」で在庫を調整する。

2諸経費・費用の仕訳

日々の営業活動にともなう諸経費は、内容に応じて適切な費用の勘定科目を使い分ける。費用が発生したときは借方に記入し、支払いに用いた現金・預金などの資産の減少を貸方に記入する。

勘定科目分類主な内容
旅費交通費費用電車代・バス代・タクシー代など交通費全般
広告宣伝費費用新聞広告・チラシなど宣伝のための支出
支払利息費用借入金にかかる利息の支払い
受取利息収益預金や貸付金にかかる利息の受取り
保険料費用火災保険など保険契約にかかる支払い(支払時に全額費用計上する)
租税公課費用固定資産税・印紙税など(法人税等を除く)事業に関する税金
見本品費費用商品を見本として無償提供した場合の原価相当額
例題: 旅費交通費 取引: 電車代1,200円を現金で支払った。
仕訳: (借方)旅費交通費 1,200円 / (貸方)現金 1,200円
例題: 広告宣伝費 取引: 新聞折込広告の代金15,000円を現金で支払った。
仕訳: (借方)広告宣伝費 15,000円 / (貸方)現金 15,000円
例題: 受取利息 取引: 銀行預金の利息800円が当座預金口座に入金された。
仕訳: (借方)当座預金 800円 / (貸方)受取利息 800円
例題: 支払利息 取引: 借入金の利息2,000円を現金で支払った。
仕訳: (借方)支払利息 2,000円 / (貸方)現金 2,000円
例題: 保険料 取引: 建物に火災保険をかけ、1年分の保険料12,000円を現金で支払った。
仕訳: (借方)保険料 12,000円 / (貸方)現金 12,000円(支払時点では全額を費用として計上し、期間按分は決算整理で行う)
例題: 租税公課 取引: 固定資産税50,000円の納税通知書を受け取り、現金で納付した。
仕訳: (借方)租税公課 50,000円 / (貸方)現金 50,000円
例題: 見本品費 取引: 得意先への見本品として、自社の商品(原価5,000円)を無償で提供した。
仕訳: (借方)見本品費 5,000円 / (貸方)仕入 5,000円(自社の仕入(費用)を取り消して、見本品費(費用)に振り替える)
つまずきやすいポイント 「受取利息」(収益・貸方)と「支払利息」(費用・借方)は名前が似ているため、貸し借りの向きを逆に覚えないよう注意する。また、保険料や家賃などは支払時に全額を費用計上し、期間未経過分の「前払費用」への振り替えは決算整理で行う点も押さえておく。
練習問題 0 / 2問 正解

問1　得意先へ向かうためのタクシー代3,500円を現金で支払った。

タクシー代などの交通費は旅費交通費(費用)として借方に記入し、減った現金を貸方に記入する。

問2　固定資産税40,000円を現金で納付した。

固定資産税や印紙税は租税公課(費用)で処理する。法人税等は会社の利益にかかる税金で、別の勘定科目を使う。

3債権債務(売掛金・買掛金)・手形・借入金/貸付金

商品売買にともない後日代金を受け払いする権利・義務は、売掛金(資産)・買掛金(負債)として処理する。手形は同様の債権債務だが、支払いを法的に保証する証券である点が異なる。借入金・貸付金は金銭消費貸借契約にもとづく債権債務である。

勘定科目分類内容
売掛金資産商品を掛けで売り上げたときの、代金を受け取る権利
買掛金負債商品を掛けで仕入れたときの、代金を支払う義務
前払金資産商品代金の一部を内金として前払いしたときの権利
前受金負債商品代金の一部を内金として受け取ったときの義務
受取手形資産約束手形を受け取ったときの手形債権
支払手形負債約束手形を振り出したときの手形債務
貸付金資産取引先などに金銭を貸し付けたときの権利
借入金負債銀行などから金銭を借り入れたときの義務
例題: 売掛金の回収 取引: 得意先に対する売掛金60,000円を、現金で回収した。
仕訳: (借方)現金 60,000円 / (貸方)売掛金 60,000円
例題: 買掛金の支払い 取引: 仕入先に対する買掛金40,000円を、現金で支払った。
仕訳: (借方)買掛金 40,000円 / (貸方)現金 40,000円
例題: 内金の支払い(前払金) 取引: 商品30,000円を注文し、内金として現金10,000円を支払った。
仕訳: (借方)前払金 10,000円 / (貸方)現金 10,000円
例題: 内金の受取り(前受金) 取引: 得意先から商品の注文を受け、内金として現金5,000円を受け取った。
仕訳: (借方)現金 5,000円 / (貸方)前受金 5,000円
例題: 約束手形の振り出し(仕入) 取引: 商品70,000円を仕入れ、代金として約束手形を振り出した。
仕訳: (借方)仕入 70,000円 / (貸方)支払手形 70,000円
例題: 約束手形の受取り(売上) 取引: 商品90,000円を売り上げ、代金として得意先が振り出した約束手形を受け取った。
仕訳: (借方)受取手形 90,000円 / (貸方)売上 90,000円
例題: 手形の裏書譲渡 取引: 買掛金50,000円の支払いのため、かねて所有していた約束手形50,000円を仕入先へ裏書譲渡した。
仕訳: (借方)買掛金 50,000円 / (貸方)受取手形 50,000円(所有する受取手形を裏書きして買掛金の支払いに充てるため、受取手形が減少する)
例題: 手形の割引 取引: 所有する約束手形100,000円を、支払期日前に銀行で割り引き、割引料3,000円を差し引かれた残額が当座預金に入金された。
仕訳: (借方)当座預金 97,000円・手形売却損 3,000円 / (貸方)受取手形 100,000円
例題: 現金の借入れ 取引: 銀行から現金500,000円を借り入れた。
仕訳: (借方)現金 500,000円 / (貸方)借入金 500,000円
例題: 現金の貸付け 取引: 取引先に現金200,000円を貸し付けた。
仕訳: (借方)貸付金 200,000円 / (貸方)現金 200,000円
つまずきやすいポイント 売掛金の回収(資産の減少・貸方)と買掛金の支払い(負債の減少・借方)、受取手形(資産)と支払手形(負債)、借入金(負債)と貸付金(資産)は、名称が似ていて左右を逆に覚えやすいので注意する。「お金を受け取る権利は資産、支払う義務は負債」という原則に立ち返って判断するとよい。
練習問題 0 / 3問 正解

問1　商品150,000円を仕入れ、代金のうち50,000円は先に支払っていた内金と相殺し、残額は掛けとした。

内金を支払ったときに前払金(資産)を計上しているので、仕入れたときにその前払金を減らす。残りの100,000円は買掛金とする。

問2　所有する約束手形200,000円を銀行で割り引き、割引料4,000円を差し引かれた残額が当座預金に入金された。

手放した受取手形200,000円を貸方に、入金された196,000円と割引料4,000円(手形売却損)を借方に記入する。

問3　商品を仕入れ、代金として約束手形を振り出した。貸方に記入する勘定科目はどれか。

約束手形を振り出した側は、手形の代金を支払う義務を負うので支払手形(負債)を貸方に記入する。受け取った側は受取手形(資産)を借方に記入する。

4固定資産の取得・売却

備品・建物など長期間にわたって使用する目的で取得した資産を固定資産という。取得時は購入代価に付随費用を加えた取得原価で資産計上する。売却するときは、取得原価から減価償却累計額を差し引いた帳簿価額を減少させる。

勘定科目内容
備品事務用什器など、長期間使用する動産(取得時は取得原価で計上する)
建物事業用の店舗・事務所など(資本的支出も取得原価に加算する)
減価償却累計額固定資産の価値の減少分を間接的に控除する評価勘定
修繕費固定資産の原状回復のための支出(収益的支出)
例題: 備品の購入 取引: 事務用の備品300,000円を購入し、代金は現金で支払った。
仕訳: (借方)備品 300,000円 / (貸方)現金 300,000円
例題: 備品の売却(売却損益なし) 取引: 取得原価500,000円、減価償却累計額300,000円の備品を200,000円で売却し、代金は現金で受け取った(売却損益は生じないものとする)。
仕訳: (借方)現金 200,000円・減価償却累計額 300,000円 / (貸方)備品 500,000円(取得原価500,000円と減価償却累計額300,000円を相殺し、帳簿価額200,000円を減少させる)
例題: 固定資産の資本的支出 取引: 事業用の建物にかかる固定資産の改良のための支出300,000円を、現金で支払った(資本的支出に該当する)。
仕訳: (借方)建物 300,000円 / (貸方)現金 300,000円(価値を高める支出のため、費用ではなく建物の取得原価に加算する)
つまずきやすいポイント 固定資産の価値を高めたり耐用年数を延ばしたりする支出(資本的支出)は建物などの資産に加算するが、単なる原状回復のための支出(収益的支出)は修繕費(費用)として処理する。この区別を誤ると、費用と資産のどちらに計上するかを間違えやすい。また固定資産売却時は、取得原価と減価償却累計額の両方を減少させることを忘れないこと。

問1　事務用の備品250,000円を購入し、運送費5,000円とともに代金は現金で支払った。

固定資産の取得原価には、購入代価に運送費などの付随費用を含める。よって備品は255,000円になる。

問2　取得原価400,000円、減価償却累計額240,000円の備品を160,000円で売却し、代金は現金で受け取った。

備品の取得原価400,000円と減価償却累計額240,000円をともに減らす。帳簿価額160,000円で売れたので売却損益は生じない。

問3　建物の外壁の汚れを落として元の状態に戻すための塗装代80,000円を、現金で支払った。

元の状態に戻すための支出(収益的支出)は修繕費(費用)とする。価値を高める改良のための支出(資本的支出)なら建物に加算する。

5現金・預金と仮払金・仮受金・現金過不足

現金には紙幣・硬貨だけでなく、他社振出の小切手のようにただちに換金できる「通貨代用証券」も含まれる。用途や金額が未確定な一時的な支出・入金は、仮払金(資産)・仮受金(負債)として処理し、内容が判明した時点で正しい勘定科目に振り替える。また現金の帳簿残高と実際有高が一致しない場合は、原因が判明するまで現金過不足として一時的に処理する。

勘定科目分類内容
現金資産紙幣・硬貨のほか、他社振出の小切手など通貨代用証券も含む
当座預金資産小切手の振り出しや振込の決済に用いる預金
仮払金資産金額や用途が未確定な支出を一時的に処理する勘定
仮受金負債内容が不明な入金を一時的に処理する勘定
現金過不足一時的な勘定現金の帳簿残高と実際有高が不一致のときに一時的に処理する勘定
例題: 当座預金への預入れ 取引: 現金100,000円を当座預金口座に預け入れた。
仕訳: (借方)当座預金 100,000円 / (貸方)現金 100,000円
例題: 他社振出の小切手の受取り 取引: 得意先から売掛金の回収として、他社振出の小切手80,000円を受け取った。
仕訳: (借方)現金 80,000円 / (貸方)売掛金 80,000円(他社振出の小切手は通貨代用証券として「現金」に含める)
例題: 仮払金 取引: 従業員が出張する際、旅費の概算額として現金30,000円を仮に渡した。
仕訳: (借方)仮払金 30,000円 / (貸方)現金 30,000円
例題: 仮受金 取引: 出張中の従業員から、内容不明の送金10,000円が当座預金口座に振り込まれた。
仕訳: (借方)当座預金 10,000円 / (貸方)仮受金 10,000円
例題: 現金過不足(実際有高が多い場合) 取引: 現金の実際有高が帳簿残高より50,000円多いことが判明したが、原因は不明である。
仕訳: (借方)現金 50,000円 / (貸方)現金過不足 50,000円(帳簿残高を実際有高に一致させるため現金を増加させ、原因判明まで現金過不足で処理する)
つまずきやすいポイント 支出時に用途が未確定なら「仮払金(資産)」、入金時に内容が不明なら「仮受金(負債)」と、左右の向きを逆にしないよう注意する。現金過不足は、実際有高に帳簿残高を合わせる方向で仕訳する一時的な勘定であり、原因が判明したら正しい勘定科目に振り替え、決算まで原因不明のままなら雑損・雑益に振り替える。

問1　得意先から売掛金70,000円の回収として、他社が振り出した小切手を受け取った。

他社が振り出した小切手はすぐに換金できる通貨代用証券なので、現金として処理する。

問2　出張前に概算額として渡していた20,000円について、従業員が帰社し、旅費18,000円を差し引いた残額を現金で受け取った。

渡したときの仮払金(資産)20,000円を取り消し、使った18,000円を旅費交通費、戻ってきた2,000円を現金とする。

問3　現金の実際有高が帳簿残高より3,000円少ないことがわかったが、原因は不明である。

帳簿の現金を実際有高に合わせるため現金を3,000円減らし(貸方)、原因がわかるまで現金過不足で処理する。

6資本(元入れ・引出し・増資)

個人企業では、事業主が事業のために出資した元手を資本金(純資産)として処理する。事業主が店のお金を私的に使った場合は、資本金を直接減らすのではなく、引出金という資本金のマイナス項目で一時的に処理する。株式会社では、株式を発行して払い込みを受けた金額を資本金として処理する。

勘定科目内容
資本金事業主や株主が出資した元手(純資産)
引出金個人企業で事業主が私的に資金を使った場合に計上する、資本金のマイナス項目
例題: 元入れ 取引: 事業開始にあたり、現金1,000,000円を元入れした。
仕訳: (借方)現金 1,000,000円 / (貸方)資本金 1,000,000円
例題: 引出金 取引: 個人企業において、事業主が店の現金50,000円を私的な生活費として引き出した。
仕訳: (借方)引出金 50,000円 / (貸方)現金 50,000円
例題: 増資 取引: 増資を行い、株式を発行して現金3,000,000円の払い込みを受けた。
仕訳: (借方)現金 3,000,000円 / (貸方)資本金 3,000,000円
つまずきやすいポイント 元入れ(資本金の増加・貸方)と引出し(引出金の増加・借方)は逆方向の取引であり、混同しないよう注意する。また期中の私的な引き出しは「資本金」を直接減らすのではなく「引出金」で処理し、決算時にまとめて資本金から差し引く点も押さえておく。
練習問題 0 / 2問 正解

問1　個人企業の事業主が、店の現金20,000円を私的な生活費として引き出した。

事業主の私的な引き出しは、資本金を直接減らさずに引出金で処理する。費用(給料など)にはならない。

問2　株式を発行して増資を行い、払込金1,000,000円が当座預金口座に入金された。

株式の払込みを受けた金額は資本金(純資産)の増加として貸方に記入する。借入金と違って返済の義務はない。

7給与の支払い

従業員に給料を支払う際は、源泉所得税や社会保険料の従業員負担分をあらかじめ天引きして支給する。天引きした金額は、後日会社が税務署や年金事務所などへ納付するまでの間、預り金(負債)として一時的に処理する。

勘定科目分類内容
給料費用従業員に支払う給与の総額
預り金(社会保険料預り金)負債給料から天引きした源泉所得税・社会保険料など、後日納付するまでの一時的な預り分
法定福利費費用社会保険料のうち会社が負担する部分
例題: 給料の支払い(源泉所得税の控除) 取引: 従業員に給料300,000円を支払うにあたり、源泉所得税20,000円を差し引いた残額を現金で支払った。
仕訳: (借方)給料 300,000円 / (貸方)現金 280,000円・預り金 20,000円(給料の総額を借方に計上し、天引き分は預り金として貸方に計上する)
例題: 社会保険料の納付 取引: 給料から差し引いていた社会保険料(従業員負担分)20,000円を、会社負担分30,000円と合わせて現金50,000円で納付した。
仕訳: (借方)社会保険料預り金 20,000円・法定福利費 30,000円 / (貸方)現金 50,000円(従業員負担分は預り金の減少、会社負担分は法定福利費(費用)として処理する)
つまずきやすいポイント 給料から天引きした源泉所得税・社会保険料は、支払い時点では会社の費用にはならず「預り金(負債)」として処理する。天引き額をそのまま費用計上してしまうミスに注意する。また納付時、従業員負担分は「預り金」の減少、会社負担分は「法定福利費」(費用)として、処理する勘定科目が異なる点も区別しておく。
練習問題 0 / 2問 正解

問1　従業員に給料250,000円を支払うにあたり、源泉所得税18,000円を差し引いた残額を現金で支払った。

給料は総額250,000円を費用とし、天引きした源泉所得税は後で納付するまで預り金(負債)とする。

問2　給料から差し引いて預かっていた源泉所得税18,000円を、現金で納付した。

預かっていた税金を納めたので、預り金(負債)を減らす。会社の費用(租税公課など)にはならない。

8貸倒れと貸倒引当金

得意先の倒産などにより、売掛金や受取手形が回収できなくなることを貸倒れという。貸倒引当金が設定されていない場合は、貸倒れとなった金額の全額を貸倒損失(費用)として処理する。貸倒引当金が設定されている場合は、まずその引当金を取り崩し、引当金の額を超える部分だけを貸倒損失とする。

勘定科目分類内容
貸倒損失費用貸倒引当金が設定されていない(または不足する)場合の回収不能額
貸倒引当金資産の評価勘定あらかじめ見積もった貸倒れに備える金額(貸倒れが生じたときに取り崩して充当する)
償却債権取立益収益過去に貸倒れとして処理した債権を、当期になって回収できた場合の収益
例題: 貸倒引当金が設定されていない場合の貸倒れ 取引: 得意先が倒産し、その得意先に対する売掛金30,000円が回収不能となった(貸倒引当金の設定はなかった)。
仕訳: (借方)貸倒損失 30,000円 / (貸方)売掛金 30,000円

なお、貸倒引当金があらかじめ設定されている場合は、その範囲内で貸倒引当金を取り崩す。例えば貸倒引当金の残高が30,000円あるところに売掛金30,000円が貸し倒れた場合は、(借方)貸倒引当金 30,000円 / (貸方)売掛金 30,000円と処理し、貸倒引当金の残高を超える部分が生じたときだけ、超過額を貸倒損失(費用)として追加計上する。

例題: 償却済み債権の回収 取引: 得意先が倒産し、前期以前に貸倒れとして処理済みであった売掛金のうち10,000円を、当期になって現金で回収できた。
仕訳: (借方)現金 10,000円 / (貸方)償却債権取立益 10,000円(すでに貸倒れとして消去した債権のため、「売掛金」の増加としては処理しない)
つまずきやすいポイント 貸倒引当金が設定されているかどうかで処理が異なる(設定なし→全額を貸倒損失、設定あり→まず貸倒引当金を取り崩し、不足分のみ貸倒損失)。また、過去に貸倒れ処理した債権を回収できた場合は、すでに消去済みの「売掛金」を復活させるのではなく、「償却債権取立益(収益)」として処理する点に注意する。
練習問題 0 / 2問 正解

問1　得意先が倒産し、売掛金40,000円が回収できなくなった。貸倒引当金の残高は25,000円ある。

まず貸倒引当金25,000円を取り崩し、足りない15,000円を貸倒損失(費用)とする。

問2　前期に貸倒れとして処理していた売掛金のうち8,000円を、現金で回収した。

前期以前に貸倒れとして消した債権なので、売掛金は使わず償却債権取立益(収益)とする。

9有価証券・消費税・電子記録債権・商品券などその他の取引

仕訳ではこのほかにも、有価証券・消費税・電子記録債権・他社発行の商品券など、さまざまな取引を扱う。それぞれ使用する勘定科目と処理方法が決まっているため、個別に押さえておく。

勘定科目分類内容
有価証券資産売買目的で保有する株式・社債など
仮払消費税資産税抜方式で仕入れた商品にかかる消費税額(仕入時)
仮受消費税負債税抜方式で売り上げた商品にかかる消費税額(売上時)
電子記録債権資産電子記録機関(でんさいネット等)に記録された金銭債権
受取商品券資産他社発行の商品券を受け取ったときの、後日換金できる権利
例題: 有価証券の購入 取引: 売買を目的として株式500,000円を購入し、代金は現金で支払った。
仕訳: (借方)有価証券 500,000円 / (貸方)現金 500,000円
例題: 消費税(税抜方式)での仕入 取引: 消費税(税抜方式)を採用している場合、商品110,000円(うち消費税10,000円)を現金で仕入れた。
仕訳: (借方)仕入 100,000円・仮払消費税 10,000円 / (貸方)現金 110,000円(本体価格を仕入、消費税額を仮払消費税に区分して計上する)
例題: 電子記録債権の決済 取引: 電子記録債権(でんさい)として管理していた売掛金80,000円が、当座預金口座に入金され決済された。
仕訳: (借方)当座預金 80,000円 / (貸方)電子記録債権 80,000円
例題: 他社発行の商品券の受取り 取引: 得意先発行の商品券20,000円を受け取り、商品を売り渡した。
仕訳: (借方)受取商品券 20,000円 / (貸方)売上 20,000円
つまずきやすいポイント 消費税の税抜方式では、本体価格と消費税額を分けて記帳する(仕入時は「仮払消費税」、売上時は「仮受消費税」)。また、他社が発行した商品券を受け取ったときは「受取商品券」という資産の勘定科目を用いる点(現金と同一視しない)に注意する。

問1　消費税は税抜方式で処理している。商品66,000円(うち消費税6,000円)を売り上げ、代金は掛けとした。

税抜方式では本体価格60,000円を売上、消費税6,000円を仮受消費税(負債)に分ける。受け取る権利は税込の66,000円。

問2　商品35,000円を売り上げ、代金として他社発行の商品券30,000円と現金5,000円を受け取った。

他社発行の商品券は、後で発行元から代金を受け取れる権利なので受取商品券(資産)とする。現金とは区別する。

10決算振替仕訳

決算にあたっては、収益・費用の各勘定残高をいったん損益勘定に集計し、当期純利益(または純損失)を算定する(損益振替)。そのうえで、算定された当期純利益を資本金勘定に振り替える(資本振替)。この一連の手続きにより、収益・費用の各勘定残高はゼロになり、当期の利益が資本金に反映される。

決算振替の手続き内容
損益振替収益・費用の各勘定残高を損益勘定に振り替え、当期純利益(または純損失)を算定する
資本振替損益勘定で算定された当期純利益(純損失)を資本金勘定に振り替える
例題: 損益振替 取引: 決算にあたり、収益・費用の各勘定残高を損益勘定に振り替える。
収益(売上など)の振替: (借方)売上 ××円 / (貸方)損益 ××円
費用(仕入など)の振替: (借方)損益 ××円 / (貸方)仕入 ××円(収益は借方に、費用は貸方に記入して損益勘定に集計する)
例題: 資本振替(個人企業) 取引: 損益勘定で算定された当期純利益100,000円を、資本金勘定に振り替える。
仕訳: (借方)損益 100,000円 / (貸方)資本金 100,000円(当期純利益は資本金の増加要因となる)
つまずきやすいポイント 損益振替では、収益は借方に、費用は貸方に記入して損益勘定に集計する(通常の仕訳とは逆側に記入するイメージ)。また、当期純利益が生じた場合は資本金の貸方に振り替える(資本金が増加する)が、当期純損失の場合は逆に資本金の借方に振り替える(資本金が減少する)点も押さえておく。
練習問題 0 / 2問 正解

問1　決算にあたり、売上勘定の残高800,000円を損益勘定に振り替えた。

収益の勘定は貸方に残高があるので、借方に記入して残高をゼロにし、損益勘定の貸方に集める。

問2　個人企業で、損益勘定で算定された当期純利益150,000円を資本金勘定に振り替えた。

当期純利益は資本金を増やすので、資本金の貸方に振り替える。株式会社なら繰越利益剰余金に振り替える。
