基礎知識のまとめ

複式簿記の考え方と、勘定科目を資産・負債・純資産・収益・費用の5つに分類する方法など、簿記を学ぶ上での土台となる基礎知識を解説します。読み終えたら下部から問題を解いて定着させましょう。

1複式簿記の考え方と借方・貸方

簿記とは、企業の取引を記録・計算し、財産や経営成績を明らかにするための技術である。現金の増減だけを記録する簡易な方法を単式簿記というのに対し、一つの取引を原因と結果の両面から捉え、「借方」と「貸方」の両方に記録する方法を複式簿記という。日商簿記検定で学ぶのはこの複式簿記である。

複式簿記では、一つの取引を借方・貸方の両方に同じ金額で記入する(これを仕訳という)。そのため、すべての取引を記録し終えた時点で、借方の合計金額と貸方の合計金額は必ず一致する。これを貸借平均の原理という。

練習問題 0 / 2問 正解

問1　一つの取引を原因と結果の両面から捉え、借方と貸方の両方に記録する方法はどれか。

取引を借方・貸方の両面から記録するのが複式簿記である。単式簿記は現金の増減だけを記録する簡易な方法である。

問2　すべての取引を仕訳して記録し終えたとき、借方の合計金額と貸方の合計金額の関係として正しいものはどれか。

仕訳では1つの取引を借方・貸方の両方に同じ金額で記入するため、合計は必ず一致する(貸借平均の原理)。

2勘定科目の5分類(資産・負債・純資産・収益・費用)

取引を記録する際に用いる項目を勘定科目という。すべての勘定科目は、資産・負債・純資産(資本)・収益・費用の5つのいずれかに分類される。この5分類と、それぞれ借方・貸方のどちら側が増加を表すのかを正しく理解することが、仕訳を学ぶ上での土台になる。

分類増加する側主な勘定科目の例
資産借方(左)現金・売掛金・備品 など
負債貸方(右)買掛金・借入金 など
純資産(資本)貸方(右)資本金 など
収益貸方(右)売上・受取手数料 など
費用借方(左)仕入・給料・支払家賃 など
例題: 勘定科目を分類する 「買掛金」「資本金」「現金」「売上」の4つの勘定科目は、それぞれ次のように分類される。
現金 → 資産 / 買掛金 → 負債 / 資本金 → 純資産 / 売上 → 収益
このように、名前だけで判断がつきにくい科目もあるため、代表的な勘定科目とその分類は一通り覚えておく必要がある。
つまずきやすいポイント 資産は借方(左)が増加、負債・純資産・収益は貸方(右)が増加というように、勘定科目の分類によって「借方・貸方のどちらが増加を表すか」が異なる。特に資産と負債は増加する側が逆になるため混同しやすい。例えば現金(資産)が増えたときは借方に記入するが、借入金(負債)が増えたときは貸方に記入する。
練習問題 0 / 3問 正解

問1　負債に分類される勘定科目はどれか。

借入金は後で返済する義務なので負債。売掛金は資産、受取手数料は収益、給料は費用である。

問2　増加(発生)したときに借方に記入する分類の組合せはどれか。

資産の増加と費用の発生は借方(左)、負債・純資産の増加と収益の発生は貸方(右)に記入する。

問3　銀行から現金300,000円を借り入れた。

現金(資産)が増えたので借方に、返済する義務である借入金(負債)が増えたので貸方に記入する。
