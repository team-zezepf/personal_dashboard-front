財務諸表のまとめ

貸借対照表と損益計算書という2つの決算書がそれぞれ何を表すのか、両者がどうつながっているのかを図解しています。読み終えたら下部から問題を解いて定着させましょう。

1貸借対照表(B/S)

貸借対照表(B/S: Balance Sheet)は、決算日などの一定時点における企業の財政状態、すなわち「何をどれだけ持っているか(資産)」「他人から調達した分(負債)」「自分のものといえる分(純資産)」を示す財務諸表である。左側に資産、右側に負債と純資産を並べ、両者の合計は必ず一致する。この関係を貸借対照表等式と呼ぶ。

貸借対照表等式 資産 = 負債 + 純資産
部区分主な勘定科目
資産の部流動資産現金、売掛金、商品 など
資産の部固定資産建物、備品、土地 など
負債の部流動負債買掛金、支払手形 など
負債の部固定負債借入金(長期のもの) など
純資産の部資本金・繰越利益剰余金株主からの出資額、過去からの利益の蓄積 など

資産・負債は、仕入→販売→代金回収という通常の営業サイクルに含まれるもの(現金・商品・売掛金・買掛金など)を流動資産・流動負債とする※。それ以外のもの(貸付金・借入金など)は、決算日の翌日から1年以内に現金化・決済されるかどうかで、流動資産・流動負債か固定資産・固定負債かを判定する。また、貸借対照表の資産は、現金化しやすいものから順に並べる流動性配列法で記載するのが一般的である。

※このように営業サイクルを基準に流動/固定を判定する考え方を正常営業循環基準、期間(1年)を基準に判定する考え方を1年基準と呼ぶ。まず正常営業循環基準を優先して適用し、それに当てはまらないものにだけ1年基準を使う、という2段階の判定になっている。

つまずきやすいポイント 現金・売掛金・商品が流動資産なのは「1年以内に現金化されるから」ではなく、通常の営業サイクルに含まれるからである(正常営業循環基準、上記の※を参照)。「1年以内かどうか」で判定するのは、営業サイクルに含まれない貸付金・借入金などに限られる。また、資産の記載順序(流動性配列法)を負債・純資産の配列と混同しないこと。
練習問題 0 / 3問 正解

問1　貸借対照表等式として正しいものはどれか。

貸借対照表の左側の資産の合計と、右側の負債と純資産の合計は必ず一致する。

問2　流動資産に分類されるものはどれか。

売掛金は仕入→販売→代金回収という通常の営業サイクルに含まれるので流動資産。建物・土地・備品は長く使う固定資産である。

問3　資産合計が900,000円、負債合計が350,000円のとき、純資産の金額はどれか。

資産 = 負債 + 純資産 なので、純資産 = 900,000 − 350,000 = 550,000円。

2損益計算書(P/L)

損益計算書(P/L: Profit and Loss Statement)は、貸借対照表とは異なり、一会計期間(通常は1年間)の収益と費用を集計し、その差額から企業の経営成績を明らかにする財務諸表である。収益合計から費用合計を差し引いた金額を当期純利益といい、費用が収益を上回る場合は当期純損失となる。

損益計算書の基本式 収益 − 費用 = 当期純利益(マイナスなら当期純損失)
区分主な勘定科目
収益売上高 など
費用売上原価(仕入)、給料、減価償却費、支払家賃、水道光熱費 など
例題: 売上総利益と当期純利益の算定 売上高1,000,000円、売上原価700,000円、給料150,000円、減価償却費30,000円の場合を考える。
売上総利益 = 売上高1,000,000円 − 売上原価700,000円 = 300,000円
費用合計 = 売上原価700,000円 + 給料150,000円 + 減価償却費30,000円 = 880,000円
当期純利益 = 収益1,000,000円 − 費用合計880,000円 = 120,000円
つまずきやすいポイント 売上総利益(粗利益)は「売上高−売上原価」で求める段階的な利益であり、給料や減価償却費などその他の費用を差し引く前の金額である。売上総利益をそのまま当期純利益と混同しないよう注意する。当期純利益は、収益合計から費用の全項目を差し引いた最終的な利益である。
練習問題 0 / 2問 正解

問1　売上高800,000円、売上原価560,000円、給料120,000円のとき、売上総利益はどれか。

売上総利益 = 売上高 − 売上原価 = 800,000 − 560,000 = 240,000円。給料はまだ差し引かない(差し引くと当期純利益の計算になる)。

問2　損益計算書が表すものはどれか。

損益計算書は一会計期間の収益と費用から経営成績を示す。一定時点の財政状態を示すのは貸借対照表である。

3純資産と当期純利益

損益計算書で計算された当期純利益は、その期の儲けを示すだけでなく、貸借対照表の純資産(資本)を増やす要素として反映される。この2つの決算書はそれぞれ独立した表ではなく、当期純利益を介してつながっている点が財務諸表を理解するうえでの要である。

株式会社の場合、純資産の部は株主が出資した金額を表す資本金と、これまでの利益の蓄積を表す繰越利益剰余金などに区分される。一方、個人企業(個人事業主)の場合は区分をせず、単に「資本」という1つの科目で純資産をまとめて表す。

個人企業における期末資本の計算式 期末資本 = 期首資本 + 当期純利益 − 引出金
例題: 個人企業の期末資本を求める 期首資本500,000円、当期純利益80,000円、事業主が私的に引き出した引出金20,000円の場合、期末資本は次のように計算する。
期末資本 = 500,000円 + 80,000円 − 20,000円 = 560,000円
つまずきやすいポイント 当期純利益は損益計算書上の数値だが、それだけで完結するのではなく貸借対照表の純資産(資本)を増加させる形で反映される。この連携を忘れて2つの表を無関係なものとして覚えてしまうと、資本の増減を問う問題でつまずきやすい。また、個人企業の「引出金」は費用ではなく、資本の払い戻しとして資本を減少させる点(株式会社の配当に近い性質)にも注意する。
練習問題 0 / 2問 正解

問1　個人企業で、期首資本600,000円、当期純利益90,000円、引出金30,000円のとき、期末資本はどれか。

期末資本 = 期首資本 + 当期純利益 − 引出金 = 600,000 + 90,000 − 30,000 = 660,000円。

問2　個人企業の引出金の説明として正しいものはどれか。

引出金は事業主が私的に使った分で、費用ではなく資本の払い戻しとして資本を減らす。
